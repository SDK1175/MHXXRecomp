# MHXX Recomp 플레이 매뉴얼 (0.2)

몬스터헌터 더블크로스 Nintendo Switch Ver. **일본판 1.5.1**을 에뮬레이터 없이 PC에서 돌리는 프로그램입니다. 한글패치를 그대로 쓸 수 있습니다.

> 이 프로그램에는 게임 파일도 한글패치도 들어 있지 않습니다. 둘 다 본인이 가진 것을 넣어야 하고, 남에게 나눠 주면 안 됩니다.

---

## 1. 준비물

| 준비물 | 설명 |
|---|---|
| `Windows-MHXXRecomp.0.2.zip` | 이 프로그램 |
| 게임 파일 | 본인 스위치에서 덤프한 **MHXX 일본판 + 1.5.1 업데이트**의 `exefs`, `romfs` 폴더 |
| 한글패치 (선택) | `MHXX_NX_1.5_kor_v2` |
| 컴퓨터 | 64비트 윈도우 10 이상, Vulkan을 지원하는 그래픽카드 |

게임 파일 덤프는 에덴(Eden) 같은 에뮬레이터에서 할 수 있습니다. 게임 우클릭 → **RomFS 덤프**, **ExeFS 덤프**. 업데이트(1.5.1)가 설치된 상태에서 덤프해야 업데이트가 합쳐진 파일이 나옵니다.

---

## 2. 설치

1. zip을 **C 드라이브가 아닌 곳**(예: `F:\Games\MHXXRecomp`)에 풉니다. 경로에 한글이 없는 편이 안전합니다.
2. 풀린 폴더의 `data` 폴더 안에 `exefs`와 `romfs` 폴더를 넣습니다.

```
MHXXRecomp\
├─ mhgurecomp.exe        ← 실행 파일
├─ mhgugame.dll
├─ data\
│  ├─ exefs\             ← 여기에 exefs
│  └─ romfs\             ← 여기에 romfs
├─ mods\                 ← 한글패치는 여기
├─ cheats\
└─ bonus\
```

3. **한글패치**: 패치 압축 파일을 `mods\` 안에 그대로 풉니다. 폴더 구조는 신경 쓰지 않아도 됩니다(`0100C3800049C000\romfs` 형태 그대로 인식). 한글패치를 빼면 순정 일본판으로 돌아갑니다.

---

## 3. 실행

- `mhgurecomp.exe`를 더블클릭합니다.
- 첫 실행은 셰이더를 준비하느라 몇십 초 더 걸릴 수 있습니다.
- 처음 나오는 물체가 잠깐 검게 보일 수 있는데, 한 번 보고 나면 다음부터는 정상입니다.

### 기존 세이브 가져오기 (에뮬레이터에서 하던 것)

1. 이 프로그램을 한 번 실행했다가 끕니다.
2. 에뮬레이터 세이브 폴더의 파일(`system`, `system_backup` 등)을 아래 폴더에 복사합니다.
   ```
   %APPDATA%\MHXXRecomp\save\save_0\
   ```
   (탐색기 주소창에 그대로 붙여넣으면 열립니다)
3. 다시 실행하면 이어서 할 수 있습니다.

> 옮기기 전에 원래 세이브를 꼭 따로 백업해 두세요.

### 종료

- 게임 안에서 **저장한 뒤** 창의 X를 누르면 "게임을 종료할까요?" 확인창이 뜹니다.
- 3초 안에 X를 한 번 더 누르면 바로 꺼집니다.
- **세이브 중(저장 아이콘이 돌 때)에는 절대 끄지 마세요.**

## 4. 조작

### 키보드 + 마우스 (기본값)

| 스위치 버튼 | 키보드 / 마우스 |
|---|---|
| 왼쪽 스틱 (이동) | W A S D (왼쪽 Shift 누른 채: 걷기) |
| 오른쪽 스틱 (시점) | 마우스 이동 |
| A | 마우스 오른쪽 |
| B | Space |
| X | 마우스 왼쪽 |
| Y | R, 마우스 가운데 |
| L | Q |
| R | E |
| ZL | Tab |
| ZR | T |
| + | Enter |
| − | Backspace |
| 십자키 | 방향키 |
| L 스틱 누르기 | Ctrl |
| R 스틱 누르기 | Alt |
| 아이템바 왼쪽 / 오른쪽 | 휠 위 / 휠 아래 |

키는 F1 → 조작 → **키 설정**에서 바꿀 수 있습니다. 키 하나당 두 개까지 지정됩니다.

**마우스 시점**: 퀘스트 중 창을 클릭하면 마우스가 잡히고 마우스로 시점이 돌아갑니다. **Esc**를 누르면 마우스가 풀립니다.

**휠 아이템바**: 사냥 중 L을 누르지 않고 휠 한 칸에 아이템이 한 칸씩 넘어갑니다.

### 프로그램 전용 키

| 키 | 기능 |
|---|---|
| **F1** | 설정 메뉴 열기 / 닫기 |
| Esc | 마우스 풀기 |
| F11 | 창 모드 ↔ 전체 화면 |
| F12 | 스크린샷 (`shots\` 폴더) |
| Shift + F12 | 연속 8장 스크린샷 |
| F7 | 안티에일리어싱(MSAA) 단계 바꾸기 |
| / | 채팅 입력 (영문) |

### 컨트롤러

- 엑스박스, 듀얼쇼크/듀얼센스, 프로콘 모두 꽂으면 바로 인식됩니다.
- 기본은 **버튼 위치 기준**입니다. 엑스박스 패드의 아래 버튼(A)이 스위치의 아래 버튼(B)이 됩니다. 글자 기준으로 바꾸려면 F1 → 조작 → 앞면 버튼 배치 → 글자 기준(권장하지 않음).
- **+ 와 − 를 함께**(엑스박스: Menu + View, 플스: Options + Share) 누르면 설정 메뉴가 열립니다.

#### 컨트롤러 버튼 바꾸기

1. F1 → 조작 → **컨트롤러 버튼**
2. 바꿀 스위치 버튼을 고르고 → **버튼 눌러서 지정**
3. 컨트롤러에서 쓰고 싶은 버튼을 누릅니다. 5초 안에 안 누르거나 Esc를 누르면 취소됩니다.
4. 맨 아래 **저장**

- **기본**은 원래 버튼, **없음**은 그 버튼을 쓰지 않는 것입니다.
- 두 버튼을 **서로 바꾸려면 둘 다** 지정해야 합니다. 하나만 바꾸면 그 버튼이 원래 역할도 같이 합니다.
- 같은 버튼을 두 곳에 넣으면 빨간 글씨로 알려 줍니다.
- 뒷버튼(패들), 트리거, 터치패드도 지정할 수 있습니다.
- 설정 메뉴 안에서는 항상 원래 버튼으로 움직이니, 잘못 지정해도 되돌릴 수 있습니다.

## 5. 설정 메뉴 (F1)

새로 설치하면 메뉴가 한국어로 나옵니다. 영어로 나오면 **Misc → Language → 한국어** 후 저장하세요(0.1에서 쓰던 설정 파일이 남아 있는 경우).

| 탭 | 주요 항목 |
|---|---|
| 화면 | 창 모드, 화면 해상도, 프레임 제한(30~240), 수직 동기화, FPS 표시 |
| 그래픽 및 오디오 | 안티에일리어싱, 부드러운 그라데이션, 음량, 백그라운드 음소거 |
| 조작 | 키 설정, 컨트롤러 버튼, 앞면 버튼 배치, 마우스 감도, 채팅 키 |
| 네트워크 | 멀티 포트, 접속 주소, 허브 서버, 매칭 키 |
| 모드 | 모드 켜고 끄기, 불러오는 순서, 충돌 확인 |
| 치트 | 치트 켜고 끄기, 치트 붙여넣기 |
| 기타 | 언어, 메뉴 테마·크기, 종료 확인 |

- 메뉴 조작: 십자키 이동, A 선택, L/R 탭 이동, X 저장, B 뒤로. 마우스로도 됩니다.
- 바꾼 뒤 **저장**을 눌러야 적용됩니다.
- 화면·조작·네트워크 일부는 재시작해야 적용됩니다(항목 옆 `*` 표시).
- 설정은 실행 파일 옆 `mhgurecomp.ini`에 저장됩니다.

### 추천 설정

- **프레임 제한**: 60 권장. 더 올려도 돌아가지만, 고프레임 보정이 아직 안 들어가서 몬스터 경직·연타 판정 등이 원작과 다르게 느껴질 수 있습니다.
- **한글 글꼴**: 윈도우의 맑은 고딕을 자동으로 씁니다. 다른 글꼴을 쓰려면 게임 폴더에 `fonts\menu.ttf`로 넣으세요.

## 6. 모드와 치트

**모드**
- `mods\` 폴더 안에 모드 폴더를 넣으면 적용됩니다. 빼면 해제됩니다(원본 파일은 바뀌지 않음).
- 에뮬레이터용 모드 구조(`romfs\`, `atmosphere\contents\...`)를 그대로 인식합니다.
- 여러 모드가 같은 파일을 바꾸면 F1 → 모드에서 순서를 정하세요(아래쪽이 우선).
- 한글패치도 모드 하나로 취급됩니다. 다른 모드와 같이 쓸 때는 순서를 확인하세요.

**치트**
- 에뮬레이터와 같은 Atmosphere 형식 치트를 씁니다. **일본판 1.5.1(빌드 ID `9D4C86E6EF74504A`)용**이어야 합니다.
- `cheats\` 폴더에 넣거나, F1 → 치트 → 치트 추가에 붙여넣으면 됩니다.
- 저장하면 바로 켜지고 꺼집니다.
- 멀티에서는 같이 하는 사람 모두가 동의할 때만 쓰세요.

## 7. 멀티플레이

게임의 **로컬 통신(ローカル通信) 집회소**를 인터넷으로 이어 줍니다. 게임의 "인터넷 통신"은 닌텐도 서버가 필요해서 되지 않습니다.

> MHXX에서는 아직 실제로 테스트하지 않았습니다. 문제가 있으면 양쪽 `log.txt`를 보내 주세요.

**같은 공유기(같은 집)**: 아무 설정 없이 집회소 찾기에 바로 나옵니다.

**다른 곳에 있는 친구와 (가상 랜 추천)**
1. 둘 다 Radmin VPN, ZeroTier, Tailscale 중 하나를 깔고 같은 네트워크에 들어갑니다.
2. 방장이 로컬 통신으로 집회소를 만듭니다.
3. 친구는 F1 → 네트워크 → **접속 주소**에 방장의 가상 랜 IP를 넣고 저장, 재시작합니다.
4. 친구가 집회소 찾기를 하면 방장 방이 나옵니다.

**포트 포워딩으로**: 방장 공유기에서 **39500 TCP/UDP**를 열고, 친구는 접속 주소에 방장의 공인 IP를 넣습니다.

**허브 서버**: 이 버전은 기본 허브 서버가 없습니다. 누군가 서버를 따로 띄운 경우에만 F1 → 네트워크 → 허브 서버에 주소를 넣습니다.

모두 **같은 버전**(0.2)을 써야 합니다.

## 8. 문제 해결

| 증상 | 해결 |
|---|---|
| 실행하자마자 꺼짐 / 게임 파일 오류 | `data\exefs`, `data\romfs`가 제대로 들어갔는지, **1.5.1 업데이트가 합쳐진** 덤프인지 확인 |
| 한글이 안 나옴 | 한글패치가 `mods\` 안에 있는지, F1 → 모드에서 켜져 있는지 확인 |
| 설정 메뉴 글자가 네모(□)로 나옴 | 한글 글꼴을 못 찾은 것. 게임 폴더에 `fonts\menu.ttf`로 한글 글꼴을 넣기 |
| 설정 메뉴가 영어 | F1 → Misc → Language → 한국어 → 저장 |
| 이름 입력이 안 됨 | 커마 메뉴의 **첫 칸 "이름"**에서 입력. PC 키보드로 영문 입력 후 Enter |
| 게임 안에서 한글 입력이 안 됨 | 한글패치 자체가 한글 입력을 지원하지 않음 (영문만 가능) |
| 처음 보는 물체가 잠깐 검게 나옴 | 셰이더 준비 중. 한 번 보고 나면 정상 |
| 마우스가 창 밖으로 안 나감 | Esc |
| 컨트롤러 버튼이 엉뚱하게 눌림 | F1 → 조작 → 컨트롤러 버튼 → 컨트롤러 버튼 초기화 |
| 창이 안 꺼짐 | X를 3초 안에 두 번. 그래도 안 되면 작업 관리자 (세이브 중엔 금지) |

문제를 알릴 때는 게임 폴더의 **`log.txt`** 를 같이 보내 주세요. 실행할 때마다 새로 쓰이니 문제가 생긴 직후의 파일이 필요합니다.

## 9. 아직 안 되는 것

- 고프레임 보정 (60fps 넘게 하면 몬스터 경직, 점프, 연타 판정 등이 원작과 다를 수 있음)
- 렌더링 해상도, 화면비, 시야각, FSR
- 몬스터 체력 배율, 집회소에서 마을 퀘스트, 소형 몬스터 동기화, 디스코드 상태 표시, 보너스 콘텐츠
- 게임 안 한글 입력 (한글패치 한계)

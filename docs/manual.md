# MHXX Recomp 플레이 매뉴얼 (0.9)

몬스터헌터 더블크로스 Nintendo Switch Ver. **일본판 1.5.1**을 에뮬레이터 없이 PC에서 돌리는 프로그램입니다. 한글패치를 그대로 쓸 수 있습니다.

> 이 프로그램에는 게임 파일도 한글패치도 들어 있지 않습니다. 둘 다 본인이 가진 것을 넣어야 하고, 남에게 나눠 주면 안 됩니다.

---

## 1. 준비물

| 준비물 | 설명 |
|---|---|
| `Windows-MHXXRecomp.0.7.zip` | 이 프로그램 |
| 게임 파일 | 본인 스위치에서 뽑은 **MHXX 일본판 (NSP/XCI) + 1.5.1 업데이트 (NSP) + prod.keys**. 또는 에뮬레이터로 덤프한 `exefs`, `romfs` 폴더 |
| 한글패치 (선택) | `MHXX_NX_1.5_kor_v2` |
| 컴퓨터 | 64비트 윈도우 10 이상, Vulkan을 지원하는 그래픽카드 |

게임 파일과 키는 이 프로그램에 들어 있지 않고, 뽑는 방법도 안내하지 않습니다. 본인 스위치와 본인 게임에서 뽑은 것만 사용하세요.

---

## 2. 설치

1. zip을 **C 드라이브가 아닌 곳**(예: `F:\Games\MHXXRecomp`)에 풉니다. 경로에 한글이 없는 편이 안전합니다.
2. `mhxx-launcher.exe`를 실행하면 **게임 파일 설치** 화면이 나옵니다. 아래 파일을 **찾아보기**로 고르고 **설치**를 누르면 런처가 알아서 넣어 줍니다(몇 분 걸림).

   | 고를 파일 | 설명 |
   |---|---|
   | 게임 원본 (1.0.0) | 본인 스위치에서 뽑은 MHXX 일본판 **NSP 또는 XCI** |
   | 업데이트 (1.5.1) | 1.5.1 업데이트 **NSP** |
   | 키 파일 | 본인 스위치에서 뽑은 **prod.keys**. 에뮬레이터(Eden 등)에 넣어 둔 게 있으면 자동으로 찾음 |
   | 한글패치 (선택) | `MHXX_NX_1.5_kor_v2` **zip** 파일. 7z나 rar면 풀어서 zip으로 다시 묶어 주세요 |

   - 1.5.1이 아닌 업데이트, 키가 안 맞는 파일, 원본과 업데이트를 바꿔 고른 경우는 설치 전에 알려 줍니다.
   - 실패하면 런처 폴더의 `install.log`에 이유가 남습니다.
   - 나중에 다시 하려면 런처 왼쪽의 **게임 파일 설치** 버튼.

   직접 넣고 싶다면(에뮬레이터로 덤프한 폴더가 있는 경우) 예전처럼 `data` 폴더 안에 `exefs`와 `romfs` 폴더를 넣어도 됩니다.

```
MHXXRecomp\
├─ mhxx-launcher.exe     ← 런처 (보통 이걸로 실행)
├─ MHXX Recomp.exe       ← 게임
├─ mhxx-texextract.exe   ← 텍스처 뽑기 (런처의 고해상도 텍스처가 씀)
├─ mhgugame.dll
├─ data\
│  ├─ exefs\             ← 여기에 exefs
│  └─ romfs\             ← 여기에 romfs
├─ mods\                 ← 한글패치는 여기
├─ cheats\
└─ bonus\
```

3. **한글패치를 직접 넣을 때**: 패치 압축 파일을 `mods\` 안에 그대로 풉니다. 폴더 구조는 신경 쓰지 않아도 됩니다(`0100C3800049C000\romfs` 형태 그대로 인식). 한글패치를 빼면 순정 일본판으로 돌아갑니다.

## 3. 실행

### 런처

- `mhxx-launcher.exe`를 더블클릭합니다.
- **처음 실행할 때** "바탕화면에 런처 바로가기를 만들까요?"가 뜹니다. 이름을 바꿀 수 있고(기본 `MHXX Recomp`), **아니요**를 누르면 만들지 않고 바로 런처로 들어갑니다. 한 번 답하면 다시 묻지 않습니다.
- 런처 배경과 로고는 내 게임 파일의 타이틀 화면에서 가져옵니다. 게임 파일이 없으면 무늬만 나옵니다.
- 오른쪽에서 **재시작해야 적용되는 설정**(창 모드, 해상도, 렌더링 해상도, 모드 등)을 게임을 켜기 전에 바꿀 수 있습니다. 나머지 설정은 게임 안 F1 메뉴에 있습니다.
- **게임 시작**: 설정을 저장하고 게임을 켭니다(컨트롤러 + 버튼으로도 됨). 런처는 닫힙니다.
- **종료**: 저장하지 않은 변경이 있으면 저장 후 종료 / 저장하지 않고 종료 / 취소를 묻습니다.
- 게임이 켜져 있는 동안 런처를 열면 "게임 실행 중"이 뜨고 시작과 설정 변경이 막힙니다. 게임을 끄면 풀립니다.
- 런처를 켤 때 PC를 검사해서, CPU가 AVX2를 지원하지 않거나 Vulkan 1.2를 쓸 수 있는 그래픽카드(드라이버)가 없으면 미리
  알려 줍니다(**다시 보지 않기** 가능).

### 도구

왼쪽 아래 **도구** 버튼.

| 탭 | 하는 일 |
|---|---|
| **세이브 백업** | **지금 백업하기**: 세이브를 게임 폴더의 `backups\`에 날짜별 zip으로 보관. **복원**: 그 시점으로 되돌림(지금 세이브는 먼저 자동 백업). **자동 백업**(기본 켬): 게임 시작 전과 업데이트 전에 백업하고 최근 10개만 남김(직접 만든 백업은 지우지 않음) |
| **모드 설치** | 모드의 `.zip`·`.7z` 파일이나 폴더를 고르면 `mods\` 안에 그 이름의 폴더로 풀어 넣음(같은 이름은 바꿔 넣음). 그다음 오른쪽 **모드**에서 켜고 순서 정하기. `.rar`는 압축을 푼 뒤 폴더로 고르기 |
| **PC 사양** | 운영체제, CPU와 AVX2, 메모리, 그래픽카드, Vulkan 버전, 남은 용량. 문제가 있으면 빨간 글씨로 |
| **캐시** | 셰이더 캐시(`cache\`) 크기와 **캐시 지우기**. 업데이트나 드라이버 교체 뒤 화면이 깨지거나 시작할 때 멈추면 지워 보기 |
| **문제 보고** | 로그, 설정, PC 사양을 zip 하나(`reports\`)로. 멀티 주소·매칭 키·Windows 사용자 이름은 빠짐. GitHub Issues에 첨부 |

세이브 복원, 모드 설치, 캐시 지우기는 게임이 꺼져 있을 때만 됩니다.

### 업데이트

- 런처를 켜면 GitHub에 새 버전이 있는지 확인합니다. 있으면 **패치 노트**와 함께 "새로운 업데이트를 다운받으시겠습니까?"가 뜹니다.
- **네**: 받아서(파일 크기와 SHA-256 검사) 설치한 뒤 런처가 다시 켜집니다. 설정, 세이브, 모드, 게임 파일(`data`), 텍스처(`textures`)는 건드리지 않습니다.
- **아니오**: 이번엔 넘어갑니다. 왼쪽 **버전** 줄의 "업데이트 있음"을 누르면 다시 볼 수 있습니다.
- 게임이 켜져 있으면 설치하지 않습니다(게임을 끄고 다시).
- F1 → 메뉴 옵션 → **업데이트**: 묻기(기본) / 자동(묻지 않고 설치) / 끔(확인 안 함).
- 기록은 `update\update.log`.

### 게임

- 런처 없이 `MHXX Recomp.exe`를 바로 실행해도 됩니다(이 경우 업데이트 확인은 하지 않음).
- 첫 실행은 셰이더를 준비하느라 몇십 초 더 걸릴 수 있습니다.
- 처음 나오는 물체가 잠깐 검게 보일 수 있는데, 한 번 보고 나면 다음부터는 정상입니다.

### 기존 세이브 가져오기 (에뮬레이터에서 하던 것)

1. 이 프로그램을 한 번 실행했다가 끕니다.
2. 에뮬레이터 세이브 폴더의 파일(`system`, `system_backup` 등)을 아래 폴더에 복사합니다.
   ```
   %APPDATA%\MHXXRecomp\save\save_0\
   ```
   (탐색기 주소창에 그대로 붙여넣으면 열립니다)
3. 다시 실행하면 이어서 할 수 있습니다.

> 옮기기 전에 원래 세이브를 꼭 따로 백업해 두세요. 이미 이 프로그램에서 하던 세이브가 있다면 런처 **도구 → 세이브 백업 →
> 지금 백업하기**로 먼저 보관해 두세요.

### 종료

- 게임 안에서 **저장한 뒤** 창의 X를 누르거나 F1 → 메뉴 옵션 → **런처로 나가기** / **바탕화면으로 나가기**를 고릅니다.
- "어디로 나가시겠습니까?" 창에서 **런처로 나가기**(런처가 다시 열림), **바탕화면으로 나가기**(그냥 종료), **취소**를 고릅니다. 실수 방지를 위해 처음 커서는 취소에 있습니다.
- 런처가 없는 폴더에서는 "정말 나가시겠습니까?" 네 / 아니오로 묻습니다.
- 창의 X를 3초 안에 한 번 더 누르면 바로 꺼집니다.
- **세이브 중(저장 아이콘이 돌 때)에는 절대 끄지 마세요.**

## 4. 조작

### 키보드 + 마우스 (기본값)

| 스위치 버튼 | 키보드 / 마우스 |
|---|---|
| 왼쪽 스틱 (이동) | W A S D (왼쪽 Shift 누른 채: 걷기) |
| 오른쪽 스틱 (시점) | 마우스 이동 |
| A | 마우스 오른쪽 |
| B | Space |
| X | 마우스 왼쪽 |
| Y | R, 마우스 가운데 |
| L | Q |
| R | E |
| ZL | Tab |
| ZR | T |
| + | Enter |
| − | Backspace |
| 십자키 | 방향키 |
| L 스틱 누르기 | Ctrl |
| R 스틱 누르기 | Alt |
| 아이템바 왼쪽 / 오른쪽 | 휠 위 / 휠 아래 |

키는 F1 → 조작 → **키 설정**에서 바꿀 수 있습니다. 키 하나당 두 개까지 지정됩니다.

**마우스 시점**: 퀘스트 중 창을 클릭하면 마우스가 잡히고 마우스로 시점이 돌아갑니다. **Esc**를 누르면 마우스가 풀립니다.

**휠 아이템바**: 사냥 중 L을 누르지 않고 휠 한 칸에 아이템이 한 칸씩 넘어갑니다.

### 프로그램 전용 키

| 키 | 기능 |
|---|---|
| **F1** | 설정 메뉴 열기 / 닫기 |
| Esc | 마우스 풀기 |
| F11 | 창 모드 ↔ 전체 화면 |
| F12 | 스크린샷 (`shots\` 폴더) |
| Shift + F12 | 연속 8장 스크린샷 |
| / | 채팅 입력 (영문) |

### 컨트롤러

- 엑스박스, 듀얼쇼크/듀얼센스, 프로콘 모두 꽂으면 바로 인식됩니다.
- 기본은 **버튼 위치 기준**입니다. 엑스박스 패드의 아래 버튼(A)이 스위치의 아래 버튼(B)이 됩니다. 글자 기준으로 바꾸려면 F1 → 조작 → 앞면 버튼 배치 → 글자 기준(권장하지 않음).
- **+ 와 − 를 함께**(엑스박스: Menu + View, 플스: Options + Share) 누르면 설정 메뉴가 열립니다.

#### 컨트롤러 버튼 바꾸기

1. F1 → 조작 → **컨트롤러 버튼**
2. 바꿀 스위치 버튼을 고르고 → **버튼 눌러서 지정**
3. 컨트롤러에서 쓰고 싶은 버튼을 누릅니다. 5초 안에 안 누르거나 Esc를 누르면 취소됩니다.
4. 맨 아래 **저장**

- **기본**은 원래 버튼, **없음**은 그 버튼을 쓰지 않는 것입니다.
- 두 버튼을 **서로 바꾸려면 둘 다** 지정해야 합니다. 하나만 바꾸면 그 버튼이 원래 역할도 같이 합니다.
- 같은 버튼을 두 곳에 넣으면 빨간 글씨로 알려 줍니다.
- 뒷버튼(패들), 트리거, 터치패드도 지정할 수 있습니다.
- 설정 메뉴 안에서는 항상 원래 버튼으로 움직이니, 잘못 지정해도 되돌릴 수 있습니다.

## 5. 설정 메뉴 (F1)

새로 설치하면 메뉴가 한국어로 나옵니다. 영어로 나오면 **Misc → Language → 한국어** 후 저장하세요(0.1에서 쓰던 설정 파일이 남아 있는 경우).

| 탭 | 주요 항목 |
|---|---|
| 화면 | 창 모드, 화면 해상도, 렌더링 해상도, 화면비, 시야각, 프레임 제한(30~240), 수직 동기화, FPS 표시 |
| 그래픽 및 오디오 | 안티에일리어싱, 부드러운 그라데이션, 음량, 백그라운드 음소거 |
| 조작 | 키 설정, 컨트롤러 버튼, 앞면 버튼 배치, 마우스 감도, 채팅 키 |
| 네트워크 | 멀티 포트, 접속 주소, 허브 서버, 매칭 키 |
| 모드 | 모드 켜고 끄기, 불러오는 순서, 충돌 확인 |
| 치트 | 치트 켜고 끄기, 치트 붙여넣기 |
| 기타 | 몬스터 체력 배율, 허브, 디스코드 (MHXX 미적용, 10장 참고) |
| 메뉴 옵션 | 언어, 메뉴 테마·크기, 종료 확인, 세이브 위치, 런처로 나가기 / 바탕화면으로 나가기 |

- 메뉴 조작: 십자키 이동, A 선택, L/R 탭 이동, X 저장, B 뒤로. 마우스로도 됩니다.
- 바꾼 뒤 **저장**을 눌러야 적용됩니다.
- 화면·조작·네트워크 일부는 재시작해야 적용됩니다(항목 옆 `*` 표시).
- 설정은 실행 파일 옆 `mhgurecomp.ini`에 저장됩니다.

### 추천 설정

- **프레임 제한**: 120~240도 문제없습니다. 몬스터 움직임, 점프, 동시 입력은 고프레임에 맞게 보정됩니다. 다만 연타 판정(기절에서 깨어나기 등)과 몬스터의 표적 고르기는 아직 보정 전이라 원작과 조금 다를 수 있습니다.
- **이방성 필터링**: 16x(기본). 비스듬히 보이는 바닥과 벽이 선명해지고 부담은 거의 없습니다.
- **시야각**: 1.0이 원작. 1.2~1.3 정도면 넓게 보입니다.
- **FSR**: 그래픽카드가 약하면 켜 보세요. 렌더링 해상도를 낮춰 그린 뒤 선명하게 키워 줍니다.
- **동시 입력 허용 시간**: 넉넉하게(기본)면 어떤 프레임에서도 스위치와 같은 감각입니다.
- **마을 이벤트**: 새 시설 소개 같은 카메라 이벤트는 **A**를 누르면 빨리 넘어갑니다(원작에 없는 기능).
- **메뉴 테마**: 메뉴 옵션 → 메뉴 테마. 골드 / 블루 / 헌터 / **더블 크로스**(런처와 같은 남색과 금테). 채팅창 색도 같이 바뀝니다.
- **한글 글꼴**: 윈도우의 맑은 고딕을 자동으로 씁니다. 다른 글꼴을 쓰려면 게임 폴더에 `fonts\menu.ttf`로 넣으세요.

## 6. 모드와 치트

**모드**
- `mods\` 폴더 안에 모드 폴더를 넣으면 적용됩니다. 빼면 해제됩니다(원본 파일은 바뀌지 않음).
- 에뮬레이터용 모드 구조(`romfs\`, `atmosphere\contents\...`)를 그대로 인식합니다.
- 여러 모드가 같은 파일을 바꾸면 F1 → 모드에서 순서를 정하세요(아래쪽이 우선).
- 한글패치도 모드 하나로 취급됩니다. 다른 모드와 같이 쓸 때는 순서를 확인하세요.

**치트**
- 에뮬레이터와 같은 Atmosphere 형식 치트를 씁니다. **일본판 1.5.1(빌드 ID `9D4C86E6EF74504A`)용**이어야 합니다.
- `cheats\` 폴더에 넣거나, F1 → 치트 → 치트 추가에 붙여넣으면 됩니다.
- 저장하면 바로 켜지고 꺼집니다.
- 멀티에서는 같이 하는 사람 모두가 동의할 때만 쓰세요.

## 7. 고해상도 텍스처 팩

장비·몬스터 텍스처를 AI로 키운 고해상도 텍스처를 쓸 수 있습니다. 게임 파일을 바꾸지 않으므로 한글패치와 같이 써도 됩니다.

- 게임 폴더의 `textures\load\`에 `<16자리 이름>.png` 파일을 넣으면, 같은 이름의 원본 텍스처 대신 그 그림을 씁니다(하위 폴더도 읽음. 런처가 만든 팩은 `gear`, `monsters` 폴더로 나뉨).
- 그림은 원본과 **가로세로 비율이 같아야** 합니다(2배, 4배 등).
- 게임을 켤 때 목록을 읽으므로 넣은 뒤에는 재시작하세요.
- 잘 들어갔는지는 `log.txt`의 `[texpack] texture pack: N pictures` 줄로 확인합니다.

### 만들기: 런처에서 (권장)

배포판에는 고해상도 텍스처가 들어 있지 않습니다(게임 그림을 가공한 것이라 나눠 줄 수 없음). 대신 런처가 **내 게임 파일로 내 PC에서** 만들어 줍니다. Vulkan을 지원하는 그래픽카드가 필요합니다.

1. 런처 왼쪽의 **고해상도 텍스처** 버튼.
2. 만들 것을 고릅니다.
   - **방어구·무기·오토모 장비**: 4배 (128 → 512). 흐릿함이 가장 크게 좋아집니다.
   - **몬스터**: 2배 (1024 → 2048).
3. **만들기**. 진행 막대와 남은 시간이 나옵니다.
   - 처음에는 게임 파일에서 텍스처를 뽑습니다(`textures\extracted`, 한 번만. 한글패치 텍스처도 같이).
   - 처음 한 번은 업스케일 프로그램(Real-ESRGAN, 약 40MB)을 GitHub에서 받습니다(`realesrgan` 폴더).
   - 컬러 텍스처는 AI(애니메 모델)로, 노멀맵·마스크는 일반 확대로 키워 `textures\load`에 넣습니다.
   - **중지**를 눌러도 만든 것은 남고, 다음에 다시 누르면 이어서 합니다.
4. 다 되면 게임을 시작하면 적용됩니다.

시간은 그래픽카드에 따라 다릅니다(작성자 PC: 장비 컬러 7,637개에 약 11분).

### 이전 폴더의 팩 가져오기

새 버전을 다른 폴더에 풀었다면 다시 만들 필요 없이, 고해상도 텍스처 화면 아래 **다른 폴더에서 텍스처 팩 가져오기**로 이전 게임 폴더를 고르세요. 팩(과 뽑아 둔 텍스처)이 이 폴더로 복사됩니다.

### 어떤 텍스처를 쓸지 고르기 (저사양 PC)

F1 또는 런처 → 그래픽 및 오디오 → **고해상도 텍스처** (재시작 필요).

| 선택 | 쓰는 것 |
|---|---|
| 자동 (기본) | 그래픽카드 메모리를 보고 아래 셋 중 하나를 고름 |
| 꺼짐 | 원래 텍스처 |
| 장비만 | 방어구·무기·오토모 장비 (부담 적음) |
| 장비+몬스터 | 몬스터까지 (2048 크기라 그래픽카드 메모리를 많이 씀) |

- 그래픽카드 메모리는 직접 찾아볼 필요 없이, 이 항목의 설명과 런처의 고해상도 텍스처 화면에 **"이 PC의 그래픽카드: 이름, 메모리 N GB. 추천: …"**으로 나옵니다.
- 추천 기준: 전용 메모리 1.5GB 미만이면 꺼짐, 3.5GB 미만이면 장비만, 그 이상이면 장비+몬스터. 내장 그래픽은 장비만까지.
- 게임이 끊기거나 그래픽 메모리 부족으로 꺼지면 한 단계 낮춰 보세요.

### 만들기: 명령어로 (소스 폴더가 있는 경우)

필요한 것: 이 프로그램의 소스 폴더(빌드 환경), 파이썬, Vulkan을 지원하는 그래픽카드.

1. **원본 텍스처 뽑기** (MSYS2 UCRT64, 소스 폴더에서. 수십 분 걸림)
   ```
   sh tools/texextract/build.sh
   ./build/mhxx-texextract.exe ../game/romfs ../textures_all2
   ```
   `textures_all2\index.txt`에 텍스처마다 크기, 종류(color / normal / mask), 게임 안 이름이 적힙니다. 이름 첫 부분이 분류입니다: player 방어구, weapon 무기, otomo 오토모, enemy 몬스터, stage 맵.
2. **업스케일** (명령 프롬프트, 소스 폴더에서. 처음 실행 때 업스케일 프로그램을 자동으로 받음)
   ```
   tools\venv\Scripts\python.exe -m pip install pillow
   tools\venv\Scripts\python.exe tools\texpack\upscale.py ..\textures_all2 build\textures\load
   tools\venv\Scripts\python.exe tools\texpack\upscale.py ..\textures_all2 build\textures\load --groups enemy --scale 2
   ```
3. 게임 실행.

### 원본 텍스처만 보기 (덤프)

F1 → 그래픽 및 오디오 → **텍스처 덤프**를 켜면, 게임에 나온 텍스처가 `textures\dump\`에 같은 이름 규칙의 PNG로 저장됩니다. 뽑기 도구로 대부분 얻을 수 있으므로 보통은 필요 없습니다.

### 주의

- 업스케일 텍스처도 게임 원본을 가공한 것이라 남에게 나눠 주면 안 됩니다. 각자 런처로 만들어 쓰세요.
- 업스케일 텍스처는 압축 없이 그래픽카드에 올라갑니다. 장비와 몬스터까지는 문제없지만, 맵(stage)까지 키우면 그래픽카드 메모리가 부족할 수 있습니다.
- UI(gui)는 글자가 뭉개져서 업스케일 대상에서 뺐습니다.

## 8. 멀티플레이

게임의 **로컬 통신(ローカル通信) 집회소**를 인터넷으로 이어 줍니다. 게임의 "인터넷 통신"은 닌텐도 서버가 필요해서 되지 않습니다.

> MHXX에서는 아직 실제로 테스트하지 않았습니다. 문제가 있으면 양쪽 `log.txt`를 보내 주세요.

**같은 공유기(같은 집)**: 아무 설정 없이 집회소 찾기에 바로 나옵니다.

**다른 곳에 있는 친구와 (가상 랜 추천)**
1. 둘 다 Radmin VPN, ZeroTier, Tailscale 중 하나를 깔고 같은 네트워크에 들어갑니다.
2. 방장이 로컬 통신으로 집회소를 만듭니다.
3. 친구는 F1 → 네트워크 → **접속 주소**에 방장의 가상 랜 IP를 넣고 저장, 재시작합니다.
4. 친구가 집회소 찾기를 하면 방장 방이 나옵니다.

**포트 포워딩으로**: 방장 공유기에서 **39500 TCP/UDP**를 열고, 친구는 접속 주소에 방장의 공인 IP를 넣습니다.

**허브 서버**: 이 버전은 기본 허브 서버가 없습니다. 누군가 서버를 따로 띄운 경우에만 F1 → 네트워크 → 허브 서버에 주소를 넣습니다.

모두 **같은 버전**(0.4)을 써야 합니다.

## 9. 문제 해결

| 증상 | 해결 |
|---|---|
| 실행하자마자 꺼짐 / 게임 파일 오류 | `data\exefs`, `data\romfs`가 제대로 들어갔는지, **1.5.1 업데이트가 합쳐진** 덤프인지 확인 |
| 한글이 안 나옴 | 한글패치가 `mods\` 안에 있는지, F1 → 모드에서 켜져 있는지 확인 |
| 설정 메뉴 글자가 네모(□)로 나옴 | 한글 글꼴을 못 찾은 것. 게임 폴더에 `fonts\menu.ttf`로 한글 글꼴을 넣기 |
| 설정 메뉴가 영어 | F1 → Misc → Language → 한국어 → 저장 |
| 이름 입력이 안 됨 | 커마 메뉴의 **첫 칸 "이름"**에서 입력. PC 키보드로 영문 입력 후 Enter |
| 게임 안에서 한글 입력이 안 됨 | 한글패치 자체가 한글 입력을 지원하지 않음 (영문만 가능) |
| 처음 보는 물체가 잠깐 검게 나옴 | 셰이더 준비 중. 한 번 보고 나면 정상 |
| 마우스가 창 밖으로 안 나감 | Esc |
| 컨트롤러 버튼이 엉뚱하게 눌림 | F1 → 조작 → 컨트롤러 버튼 → 컨트롤러 버튼 초기화 |
| 런처에서 시작이 안 눌림 ("게임 실행 중") | 게임이 이미 켜져 있음. 게임을 끄면 1초 안에 풀림. 게임 창이 안 보이면 작업 관리자에서 `MHXX Recomp.exe` 확인 |
| 런처를 다시 빌드할 때 "Permission denied" | 런처가 켜져 있음. 닫고 다시 빌드 |
| 창이 안 꺼짐 | X를 3초 안에 두 번. 그래도 안 되면 작업 관리자 (세이브 중엔 금지) |
| 업데이트·드라이버 교체 뒤 화면이 깨짐, 시작할 때 멈춤 | 런처 **도구 → 캐시 → 캐시 지우기** |
| 세이브가 날아감 / 잘못 덮어씀 | 런처 **도구 → 세이브 백업**에서 그 전 백업을 **복원** |

문제나 원하는 기능은 [구글 폼](https://docs.google.com/forms/d/e/1FAIpQLScC3lvrLqtWjTighlP7S_UbcYKcbeIt0gnN29hMizKGI6MA5Q/viewform)으로 로그인 없이 남길 수 있습니다. GitHub Issues에 올릴 때는 런처 **도구 → 문제
보고 → 문제 보고 파일 만들기**로 만든 zip을 첨부해 주세요(로그와 PC 사양이 들어 있음). 로그는 실행할 때마다 새로
쓰이니 문제가 생긴 직후에 만들어 주세요.

## 10. 아직 안 되는 것

F1 메뉴는 원래 MHGU용 프로그램의 메뉴를 그대로 가져온 것이라, **메뉴에 항목은 있지만 MHXX에서는 아직 적용되지 않는 설정**이 있습니다. 바꿔도 게임은 그대로입니다.

- 몬스터 체력 배율
- 집회소에서 마을 퀘스트
- 소형 몬스터 동기화
- 긴급 퀘스트 클리어 공유
- 디스코드 상태 표시
- 보너스 콘텐츠

그 밖에:
- 고프레임에서 연타 판정(기절·구속에서 빠져나오기 등)과 몬스터의 표적 고르기 보정
- 게임 안 한글 입력 (한글패치 한계)
- 오프닝·이벤트 영상 업스케일 (계획, 0.5 변경 내역 참고)

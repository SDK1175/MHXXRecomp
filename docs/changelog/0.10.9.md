# MHXX Recomp 0.10.9

## 새 기능

- **MHGU Skill Simulator 플러그인이 동작합니다 (덥크용 수정판)**
  - 원하는 스킬을 고르면 가진 방어구·호석·장식품으로 발동하는 조합을 찾아 주는 플러그인입니다.
  - 마을·집회소의 + 메뉴 **3페이지**에 "스킬 시뮬레이터"가 생깁니다. 퀘스트 중에는 Insert → Forge 설정 → Skill Simulator의 열기 버튼으로 엽니다.
  - 원작(ZellD-0371님)을 덥크에 맞게 고친 수정판을 써야 합니다: [MHGU Skill Simulator (MHXX Recomp용)](https://github.com/SDK1175/MHGU-Skill-Simulator/releases)

## 바뀐 점

- **플러그인을 더 많이 넣을 수 있습니다:** 플러그인용 메모리를 12MB에서 46MB로 늘렸습니다. (MHGU Utility 한글판이 10MB라 다른 플러그인이 들어갈 자리가 없었습니다)
- 플러그인이 마우스 위치·클릭·휠과 누른 키를 읽을 수 있습니다. (영미판 포팅과 같은 방식)
- 플러그인이 게임 글꼴로 쓰는 한글이 덥크 한글 패치에서 제대로 나옵니다.

## 알아 두기

- 멀티는 같이 하는 사람 모두 **0.10.9**이어야 합니다.
- 인터넷 통신(허브 서버)을 쓰면 서버 관리자에게 접속 IP와 닉네임이 보입니다. 트롤·신고 처리(밴)에만 쓰고, 접속 기록은 3일 뒤 자동으로 지워집니다. 원하지 않으면 허브 서버를 끄고 로컬 통신이나 라드민으로 하시면 됩니다.

## 테스트 환경

Windows 11, AMD 라이젠 7 5700X3D, RTX 3070 Ti (8GB), 메모리 32GB

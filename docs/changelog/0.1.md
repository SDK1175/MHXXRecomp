# MHXX Recomp 0.1

첫 테스트 빌드 (2026-11-06). `morerokk/MHGURecomp`(MHGU 1.4.0용, `ebe50a3`)를 포크해서 **몬스터헌터 더블크로스 Nintendo Switch Ver. 일본판 1.5.1**이 에뮬레이터 없이 PC에서 돌아가게 옮긴 버전.

배포 파일: `Windows-MHXXRecomp.0.1.zip` (40.8MB). 게임 파일과 한글패치는 들어 있지 않음.

## 되는 것

- 부팅 → 타이틀 → 세이브 불러오기 → 마을 → 퀘스트
- **한글패치** (`MHXX_NX_1.5_kor_v2`): `mods\` 폴더에 압축을 풀면 적용
- 다른 에뮬레이터 세이브 가져오기 (`%APPDATA%\MHXXRecomp\save\save_0\`에 넣기, 에덴에서 확인)
- 새 캐릭터 만들기와 이름 입력, 채팅 (PC 키보드로 영문 입력, Enter 확정)
- 프레임 제한 설정 (240fps에서 4.2ms까지 확인)
- F1 설정 메뉴 (그래픽, 모드, 치트, 키보드 설정)

## 바뀐 것

### 게임 대상 변경
- 타이틀 ID `0100C3800049C000`, 버전 1.5.1, 실행 파일 빌드 ID `9D4C86E6EF74504A` 검사
- 기본 언어 일본어, 창 제목 "Monster Hunter XX Nintendo Switch Ver."
- 게임 정보는 `runtime/game/game.h` 한 곳에 모음

### 한글패치 지원
- 한글패치의 exefs가 순정 1.5.1과 바이트 단위로 같은 것을 확인함. 한글화는 romfs만 바꿈
- 그래서 빌드 하나로 순정 일본판과 한글패치를 둘 다 돌릴 수 있음
- 모드 안에 게임과 똑같은 exefs가 들어 있으면 코드 모드로 읽지 않고 건너뜀 (`runtime/loader.c`)

### MHGU Recomp와 분리 (둘 다 깔아도 안 섞임)
- 데이터 폴더 `%APPDATA%\MHXXRecomp` (세이브, 설정)
- 멀티 프로토콜 이름과 버전 변경 (`MHXL`, `0x5802`), 매칭 키 솔트 변경
- 기본 허브 서버 없음 (MHGU 제작자 서버라서 뺌)
- 자동 업데이트 기본 꺼짐 (`make UPDATE_REPO=저장소`로 지정할 때만)
- 안드로이드 앱 ID `io.github.mhxxrecomp.app`

### 주소 정리
- MHGU 전용 기능이 쓰던 게임 주소 73개를 `runtime/game/addr.h`로 모음
- MHXX 주소를 채운 기능만 켜지고, 나머지는 로그 한 줄 남기고 꺼짐 (잘못된 주소를 건드려 튕기는 일 방지)
- 채운 주소:
  - 엔진 시스템 객체 `0x2348764` → 프레임 제한 설정이 실제로 적용됨
  - 매 프레임 갱신 함수 → F1 설정 메뉴가 다시 열림

### 버그 수정
- **보상 화면 배경이 깨지는 문제**: 퀘스트 사진 요청(`0xa643c8`)을 런타임에 연결해서 배경이 제대로 그려지게 함 (리컴파일 시점 패치, `tools/gen.py`)

### 정리한 것
- MHGU 전용 치트 3개, MHGU 셰이더 목록, 보너스 세이브, Forge 플러그인 제거 또는 끔
- 다른 빌드용 치트 파일(`<빌드ID>.txt`)은 읽지 않음

### 디버그 도구
- 키보드·텍스트 입력 추적 (`MHGU_KBDTRACE=1`로 켬). 이름 입력 조사에 썼고 평소엔 꺼져 있음

## 알려진 문제

- 창의 X 버튼으로 안 꺼짐 (작업 관리자로 종료, 세이브 중에는 금지)
- 고프레임에서 게임 동작 보정(몬스터 경직, 점프, 연타 판정 등) 아직 없음
- 해상도·화면비·시야각, FSR, 마우스 시점, 휠 아이템바, 로딩 가속 아직 없음
- 게임 안에서 한글 입력 불가 (한글패치 자체의 한계)

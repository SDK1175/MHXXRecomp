# MHXX Recomp 0.10.6

> **0.10.5를 받으신 분은 꼭 업데이트해 주세요.** 0.10.5 배포 파일이 예전 코드로 잘못 빌드되어, 기본 허브 서버 주소와 기타 탭 정리가 빠져 있었습니다. 런처를 켜면 업데이트 안내가 뜹니다.

## 고친 점

- **라드민 없이 인터넷 멀티가 바로 됩니다**
  - 0.10.5에서는 기본 허브 서버 주소가 빠져 있어서, 주소를 직접 넣지 않으면 방이 보이지 않았습니다.
  - 0.10.6부터는 허브 서버 칸이 비어 있으면 프로젝트 허브 서버(`mhxx-kr.duckdns.org`, 서울)를 씁니다. F1 → 네트워크 → **허브 서버 확인**에 "온라인, ○○ ms"가 나오면 됩니다.
  - 게임의 "인터넷 통신" 메뉴가 아니라 **로컬 통신** 메뉴로 집회소를 만들고 찾아야 합니다.
- **F1 → 기타 탭**: 아직 동작하지 않는 기능(몬스터 체력 배율, 집회소에서 마을 퀘스트 등)이 다시 숨겨집니다.
- **F1 → 조작의 "자이로" 항목 제거**: 0.10.5에 잘못 들어간 항목입니다. 더블크로스에는 자이로 조준 옵션이 없습니다. 자이로 센서 값은 모드용으로 그대로 넘겨줍니다.

멀티는 같이 하는 사람 모두 **0.10.6**이어야 합니다.

0.10.5에 넣으려던 내용은 [0.10.5 변경 내역](https://github.com/SDK1175/MHXXRecomp/blob/mhxx/docs/changelog/0.10.5.md)에 있습니다.

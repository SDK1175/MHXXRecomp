# MHXX Recomp 0.10.16

허브 서버 개인정보 업데이트입니다. 허브 서버(인터넷 멀티)를 쓰려면 **이 버전으로 업데이트**해야 합니다.

## 바뀐 점

- **허브 서버 이용 동의:** 런처를 처음 켜면 허브 서버가 무엇을 남기는지 보여 주고 동의를 묻습니다. **동의하기 전에는 허브 서버에 아예 접속하지 않습니다.** 동의하지 않아도 같은 공유기(LAN), 라드민 같은 가상 랜, 접속 주소로 하는 멀티는 그대로 됩니다. 나중에 F1 → 네트워크 → **허브 서버 이용 동의**에서 바꿀 수 있습니다.
- **IP 주소를 저장하지 않습니다:** 지금까지는 신고 처리를 위해 IP 주소를 관리 화면에 보여 주고 3일 동안 기록했습니다. 이제는 IP 주소를 **저장하지도, 관리자에게 보여 주지도 않습니다.** 대신 아래만 남깁니다.
  - **헌터 이름**
  - **포트 ID:** 포트가 처음에 만든 무작위 코드입니다(`ABCD-EFGH` 모양). 본인이나 PC 정보와 연결되지 않습니다. 설정 파일 옆의 `hub_id` 파일입니다.
  - **같은 주소인지 알아보는 코드:** IP를 되돌릴 수 없게 섞은 값입니다. 밴한 사람이 포트 ID를 새로 만들어 돌아오는 것을 막는 데만 씁니다.
  - 들어간 방과 시각. 이 기록은 3일 뒤 지워지고(밴된 경우만 남음), 다른 플레이어에게는 보이지 않습니다.
- 서버에 남아 있던 예전 기록과 밴 목록의 IP 주소도 모두 위의 코드로 바꿨습니다.

## 알아 두기

- **0.10.15 이하는 허브 서버를 쓸 수 없습니다.** "다른 버전" 안내가 뜨면 런처에서 업데이트해 주세요. LAN·가상 랜·접속 주소 멀티는 예전 버전도 됩니다(같이 하는 사람끼리 버전은 같아야 함).
- **신고:** 허브 서버에서 치트·비매너를 겪으면 [신고 폼](https://forms.gle/qkSwUM2SnB1zNTzR9)으로 상대의 헌터 이름과 날짜·대략의 시각을 남겨 주세요. 로그인 없이 쓸 수 있고, 내용은 운영자만 봅니다.
- 멀티는 같이 하는 사람 모두 **0.10.16**이어야 합니다.

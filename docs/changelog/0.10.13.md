# MHXX Recomp 0.10.13

## 새 기능

- **한글 채팅·이름 입력:** 게임의 채팅창과 이름 입력 칸에 키보드로 한글을 쓸 수 있습니다. 윈도우 한글 입력기를 쓰고, 한/영 키로 전환합니다. 조합 중인 글자도 입력 칸에 바로 보입니다. 덥크 한글 패치와 같은 방식으로 글자를 넣기 때문에, 한글 패치를 쓰는 다른 사람에게도 한글로 보입니다.
  - 한글 패치에 없는 글자는 ?로 바뀝니다. ㅋㅋ처럼 자음이나 모음만 쓴 글자, 똠·햏 같은 드문 글자가 여기에 해당합니다.
- **IAI SLASH HELM BREAKER 모드 동작:** 라이즈 태도의 특수 납도, 발도 베기, 투구 깨기를 쓸 수 있게 해 주는 영문판(MHGU)용 모드가 이제 덥크에서도 동작합니다. 모드는 직접 받아서 설치해야 합니다.
  - 이 모드는 게임 안의 버튼 설정을 따르지 않고, **컨트롤러의 ZR 버튼(엑스박스 패드: RT)** 을 직접 읽습니다. 게임 설정에서 기인 베기를 다른 버튼으로 바꿔 두었더라도, 모드 기술은 **RT + B / A / Y**로 씁니다.
  - **솔로 전용으로 써 주세요.** 이 모드는 새 동작을 게임에 덧붙입니다. 모드가 없는 사람에게는 그 동작이 이상하게 보이거나, 게임이 멈출 수 있습니다. 공격 판정도 바뀌어서 같이 하는 사람의 게임 진행에 영향을 줍니다.

## 고친 점

- **멀티 R3 스킵 안내:** 동의 현황("동의: 1 / 2명")이 R3를 누른 사람만이 아니라 **모두에게** 보입니다. 이 안내는 모두 동의하거나 귀환 대기가 끝날 때까지 화면에 계속 남습니다 (와일즈처럼).
- **영문판 플러그인 호환 개선:** 플러그인이 게임 안의 주소를 영문판 기준으로 비교하는 곳들을 덥크 주소로 바꿔 줍니다. 조건부 명령 안에 들어 있는 주소도 포함합니다. 이 덕분에 위 모드가 동작하고, Faster Field Hunter와 MapAssist의 같은 종류 검사도 이제 맞게 동작합니다.

## 알아 두기

- 멀티는 같이 하는 사람 모두 **0.10.13**이어야 합니다.
- 인터넷 통신(허브 서버)을 쓰면 서버 관리자에게 접속 IP와 닉네임이 보입니다. 이 정보는 트롤·신고 처리(밴)에만 쓰고, 접속 기록은 3일 뒤 자동으로 지워집니다. 원하지 않으면 허브 서버를 끄고 로컬 통신이나 라드민으로 하시면 됩니다.

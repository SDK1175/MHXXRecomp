# MHXX Recomp 0.10.5

> 멀티플레이는 같이 하는 사람 모두 **0.10.5**로 업데이트해 주세요. 런처를 켜면 업데이트 안내가 뜹니다.

## 새 기능

- **라드민 없이 인터넷 멀티**
  - 프로젝트의 **허브 서버**(서울)가 생겼습니다. 방장이 로컬 통신으로 집회소를 만들면, 친구는 집회소 찾기만 하면 방이 나옵니다.
  - Radmin VPN 같은 가상 랜, 공유기 포트 포워딩, 접속 주소 입력이 필요 없습니다. 처음 설치한 상태 그대로 됩니다.
  - 서로의 IP 주소는 상대에게 보이지 않고, 서버는 접속 기록을 남기지 않습니다.
  - 연결 확인: F1 → 네트워크 → **허브 서버 확인**에 "온라인, ○○ ms"가 나오면 됩니다.
  - 친구끼리만 하고 싶으면 **매칭 키**를 같이 정해서 넣으세요. 같은 키를 넣은 사람끼리만 방이 보입니다.
  - 라드민 등 가상 랜으로 하던 방법도 그대로 됩니다. 허브 서버를 쓰고 싶지 않으면 허브 서버 칸에 `Off`를 넣으세요.

## 바뀐 점

- **F1 → 기타 탭 정리**
  - 영문판 포팅에만 있고 XX에서는 아직 동작하지 않는 기능(집회소에서 마을 퀘스트, 소형 몬스터 동기화, 긴급 퀘스트 공유, 몬스터 체력 배율)을 메뉴에서 숨겼습니다. 켜도 아무 일이 일어나지 않아 헷갈린다는 제보를 반영했습니다.
- **자이로 센서 전달 (모드용)**
  - 듀얼쇼크 4, 듀얼센스, 스위치 프로 컨트롤러의 자이로 센서 값을 게임에 넘겨줍니다.
  - 더블크로스 자체에는 자이로 조준 기능이 없어서 게임에서 달라지는 것은 없습니다. 자이로를 쓰는 모드가 나오면 바로 동작합니다.
- **영문판 플러그인 호환 목록 갱신**: 사용자 제보로 Key Quest Markers, Monster Weakness Icons(데이터 모드라 미지원), World(like) Sharpness Gauge가 동작하지 않는 것을 확인했습니다. Sharpness Gauge는 모드 순서를 KatLib보다 위로 올리면 될 수도 있어서 확인 중입니다.
  - https://github.com/SDK1175/MHXXRecomp/blob/mhxx/docs/gu-plugins.md
- **영문판(MHGU) 세이브 안내**: 세이브 변환 프로그램으로 XX 스위치(일본판) 세이브로 바꾼 뒤, 런처의 세이브 가져오기로 넣는 방법을 설명서에 적었습니다.
  - https://github.com/SDK1175/MHXXRecomp/blob/mhxx/docs/manual.md

## 건의 답변

- **자이로 조준**: 더블크로스(스위치판)에는 원래 자이로 조준이 없어서 포팅에서 따로 넣지는 않습니다. 센서 값은 넘겨주니 모드로 나오면 쓸 수 있고, 지금 바로 쓰려면 스팀 입력에서 자이로를 오른쪽 스틱으로 설정하는 방법이 있습니다.
- **채집·채광 한 번에, 퀘스트 클리어 후 대기 넘기기**: 검토하겠습니다.

## 테스트 환경

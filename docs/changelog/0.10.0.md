| 항목 | 상태 | 내용 |

| **음성 채팅** | 🔧 (PC·친구 확인 전) | 같은 방의 이 포팅 사용자끼리. F1 → 그래픽/오디오 → 음성 채팅: **꺼짐**(기본, 마이크를 열지 않음) / **항상 켜기**(숨소리보다 큰 소리일 때만 보냄) / **누르고 말하기**(말하기 키, 기본 V · 패드 버튼: 공유·패들·터치패드·Back·스틱 클릭 중 선택). 마이크 음량 · 음성 음량 · 마이크 테스트(보낼 때처럼 압축했다 풀어서 바로 들려줌, 소리 크기 막대). 방에 있는 **사람마다 음량·음소거**(게임을 끌 때까지). 화면 왼쪽에 **말하는 사람 표시**(나: ">> 나", 다른 사람: "<< 이름"). 멀티 연결로 주고받고(방장이 다른 사람에게 전달), 사람마다 30ms 버퍼와 순서 맞추기, 빠진 패킷은 Opus FEC로 복원, 밀리면 건너뛰어 실시간 유지, 여러 명 목소리 섞기 |
| **게임 버튼 아이콘 (엑스박스 / 플레이스테이션)** | | 게임 안 버튼 아이콘(A/B/X/Y, L/R, ZL/ZR, +/−, 스틱)을 패드에 맞게: 아이콘 그림(아틀라스)을 게임이 올릴 때 포팅이 직접 그린 아이콘으로 덮음(캡콤 그림을 고쳐 배포하지 않음). 앞면 버튼 배치(위치 기준 / 글자 기준)를 따라 실제 누를 버튼을 보여 줌. F1에서 스위치 / 엑스박스 / 플레이스테이션 / 자동(꽂은 패드). 대화문 속 버튼 문자(글꼴)와 한글패치 글꼴도 확인 |
| **멀티 선택 기능** | | 소형 몬스터 동기화, 긴급 퀘스트 공유(기본 꺼짐) |

# MHXX Recomp 0.10.0

> **멀티플레이를 하시는 분은 같이 하는 사람 모두 0.10.0으로 업데이트해 주세요.** 버전이 다르면 같이 플레이할 수 없습니다(0.9.0과도 안 됩니다). 런처를 켜면 업데이트 안내가 뜹니다.

음성 채팅, 패드·키보드에 맞춘 게임 버튼 아이콘, 영문판(MHGU) Forge 플러그인 지원(실험적), 로딩 단축이 들어갔습니다. 원본 포팅(MHGU Recomp)의 개선 사항도 여럿 가져왔습니다.

## 새 기능

- **음성 채팅**: 같은 방에서 이 포팅을 쓰는 사람끼리 말로 대화할 수 있습니다.
  - F1 → 음성 채팅: **꺼짐**(기본, 마이크를 열지 않습니다) / **항상 켜기** / **누르고 말하기**(기본 V 키, 패드 버튼도 고를 수 있습니다)
  - 마이크 음량, 음성 음량, **마이크 테스트**(내 목소리를 실제로 보낼 때처럼 들려줍니다)
  - **잡음 제거**(기본 켜짐): 선풍기, 키보드, 방 안의 잡음을 지우고 보냅니다(RNNoise).
  - 목소리가 작게 들어오면 자동으로 키워서 보냅니다. 음성 음량은 게임 볼륨과 따로 정해집니다.
  - 방에 있는 **사람마다 음량·음소거**를 따로 정할 수 있습니다.
  - 화면 왼쪽에 지금 말하는 사람이 **헌터 이름**으로 표시됩니다(일본어 이름도 표시).
  - 음성은 멀티 연결로만 주고받고, 어디에도 저장하거나 따로 보내지 않습니다.
- **게임 버튼 아이콘**: 게임 안의 버튼 표시(안내 문구, HUD, 아이템 바, 지도 옆, 로비)를 쓰는 패드에 맞게 바꿉니다.
  - F1 → 컨트롤 → 게임 버튼 아이콘: **자동** / Switch / Xbox / PlayStation / **키보드**
  - 자동은 연결된 패드를 따라가고, 패드가 없으면 키보드로 표시합니다.
  - F1에서 바꾼 **버튼 설정·키 설정을 그대로 따라갑니다.** 설정을 바꾸면 재시작 없이 바로 반영됩니다.
  - 키보드는 키 이름(E, SPC, LMB, 방향키 등)을 키 모양으로 보여 줍니다.
  - 아이콘은 이 포팅이 직접 그린 그림입니다. 한글패치, 고해상도 텍스처 팩과 함께 써도 됩니다.
- **영문판(MHGU) Forge 플러그인 지원 (실험적)**: 0.7부터 가장 많이 요청해 주신 기능입니다.
  - 영문판 MHGU 1.4.0용 Forge 플러그인을 **고치지 않고 그대로** `mods\모드이름\romfs\nativeNX\plugins\`에 넣으면 동작합니다.
  - 확인된 플러그인: Damage Numbers, Better Inputs, KatLib, MapAssist, Faster Field Hunter(모두 채집·아이템 아이콘 제외)
  - 영문판과 덥크의 게임 내부가 다른 부분을 쓰는 기능은 동작하지 않을 수 있습니다. 안 되는 기능은 플러그인이 스스로 끄거나 로그에 이유를 남깁니다.
  - 세이브를 건드리는 플러그인은 **세이브를 백업한 뒤** 써 주세요.
  - 이 포팅은 어떤 모드도 배포하지 않습니다. 확인 목록과 받는 곳 안내는 `docs/gu-plugins.md`에 있습니다.
  - 텍스처·수치 같은 **데이터 모드**는 아직 지원하지 않습니다.
- **로딩 대기 줄이기**: 혼자 할 때 퀘스트 출발 대기를 줄이고, 마을·지역 이동 때 음악이 줄어드는 시간을 짧게 했습니다. 원본 포팅 기준 퀘스트 출발 5.0초 → 1.8초, 마을 이동 2.6초 → 1.4초입니다. 멀티 중에는 원래대로입니다.

## 게임

- **21:9 등 넓은 화면**: 컷신의 위아래 검은 띠가 화면 끝까지 채워지지 않던 것을 고쳤습니다.
- 그리기가 빨라졌습니다(사냥 중 렌더링 부담 약 15% 감소).
- 고해상도로 컷신을 볼 때, 또는 메모리가 적은 PC에서 시작할 때 튕기던 것을 고쳤습니다.
- 패드 진동 중에 입력이 잠깐씩 멈추던 것을 고쳤습니다.
- 고프레임에서 세 버튼 동시 입력 기술(랜스·건랜스의 R+X+A 등)이 잘 안 나가던 것을 고쳤습니다.
- 일부 반사가 검게 나오던 것, 인텔 그래픽에서 배경이 어둡던 것을 고쳤습니다.
- FXAA가 더 빨라졌습니다.
- 마우스 옆 버튼을 키 설정에 쓸 수 있습니다.

## 고마운 분

게임 쪽 개선 중 다수는 원본 포팅 **MHGU Recomp**(morerokk)에서 가져와 덥크에 맞게 옮긴 것입니다. 영문판 플러그인은 각 제작자(PurplefinNeptuna, Fexty12573, Katt404, Ellipse1638 등)의 작품입니다.

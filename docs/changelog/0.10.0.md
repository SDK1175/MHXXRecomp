| **음성 채팅** | 🔧 (마이크 테스트 ✅, 친구와 대화 확인 전) | 같은 방의 이 포팅 사용자끼리. F1 → 그래픽/오디오 → 음성 채팅: **꺼짐**(기본, 마이크를 열지 않음) / **항상 켜기**(숨소리보다 큰 소리일 때만 보냄) / **누르고 말하기**(말하기 키, 기본 V · 패드 버튼: 공유·패들·터치패드·Back·스틱 클릭 중 선택). 마이크 음량 · 음성 음량 · 마이크 테스트(보낼 때처럼 압축했다 풀어서 바로 들려줌, 소리 크기 막대). 방에 있는 **사람마다 음량·음소거**(게임을 끌 때까지). 화면 왼쪽에 **말하는 사람 표시**(나: ">> 나", 다른 사람: "<< 이름"). 멀티 연결로 주고받고(방장이 다른 사람에게 전달), 사람마다 30ms 버퍼와 순서 맞추기, 빠진 패킷은 Opus FEC로 복원, 밀리면 건너뛰어 실시간 유지, 여러 명 목소리 섞기 |
| **게임 버튼 아이콘 (엑스박스 / 플레이스테이션)** | | 게임 안 버튼 아이콘(A/B/X/Y, L/R, ZL/ZR, +/−, 스틱)을 패드에 맞게: 아이콘 그림(아틀라스)을 게임이 올릴 때 포팅이 직접 그린 아이콘으로 덮음(캡콤 그림을 고쳐 배포하지 않음). 앞면 버튼 배치(위치 기준 / 글자 기준)를 따라 실제 누를 버튼을 보여 줌. F1에서 스위치 / 엑스박스 / 플레이스테이션 / 자동(꽂은 패드). 대화문 속 버튼 문자(글꼴)와 한글패치 글꼴도 확인 |
| **로딩 대기 줄이기** | ✅ | 원본 포팅의 fastload를 일어판 주소로: 혼자 할 때 퀘스트 출발 카드 대기 생략, 마을·지역 이동 때 배경음악 페이드 1.5초/1초 → 0.3초. 원본 측정(60fps): 퀘스트 출발 5.0 → 1.8초, 마을 이동 2.6 → 1.4초, 지역 이동 1.4 → 0.7초. 멀티 중에는 원래대로 |
| **그리기 속도 개선** | ✅ | 원본 포팅에서 가져옴: 사냥 중 렌더 스레드 14~16% 절약 |
| **21:9 컷신 검은 띠** | 🔧 (PC 확인 전) | 0.9.1 대신 여기에 |
| **원본 포팅 기능 가져오기** | 🔧 (PC 확인 전) | 넣음: 패드 진동이 입력을 멈추던 문제, 고해상도 컷신 튕김(GPU 메모리 풀, 덥크 754MB 기준), 저메모리 시작 튕김, 셰이더 2개(검은 반사·인텔 어두운 배경), 마우스 옆 버튼 설정, FXAA 2배 빠르게, 인터프리터 속도, **고프레임 3버튼 입력·콤보 뒤 반복**(덥크 주소). 남음: 풀 최적화 2개(셰이더 해시 확인 필요), 로딩 표시, 굵은 글씨·글자 간격, 긴 채팅, 패드로 Forge 메뉴(Forge 켠 뒤), 조준 중 마우스 시점, 오트모어 아이템바 휠, 장식품 많은 방어구 튕김. 나중에: HDR, 지연 보상 |
| **영문판(GU) 모드·플러그인 변환** | | 0.7부터 요청이 많던 기능. ① Forge(모드 API) 켜기: 원본에서 가져와 덥크 주소 찾기(프레임 업데이트는 찾음). ② 플러그인(dll): 영문판 주소 → 일어판 주소 변환표(두 판의 코드가 일정 간격으로 밀려 있음, 구조체 위치는 대부분 같음)로 플러그인이 쓰는 주소를 바꿔 줌. 데미지 표시처럼 인기 있는 것 하나부터. ③ 데이터 모드(무기·방어구·아이템 표): 항목 ID로 맞춰 덥크에 있는 항목만 덮어쓰기, 요청 많은 표 형식부터. 외형 모드는 덥크에 같은 경로·종류가 있는 항목만, 텍스트는 제외. 먼저 원하는 모드·플러그인 목록을 받아 상위 몇 개를 목표로 |
| **멀티 선택 기능** | | 소형 몬스터 동기화, 긴급 퀘스트 공유(기본 꺼짐) |

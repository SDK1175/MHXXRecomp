# MHXX Recomp 0.3

0.2 이후 추가된 것 (2026-11-07). 리컴파일 단계를 바꿨으므로 빌드할 때 `make gen GAME=../game` 다음 `make`.

## 새로 적용되는 설정

0.2까지는 F1 메뉴에 있어도 게임에 반영되지 않던 설정들을 MHXX 게임 코드에 연결함.

| 기능 | 테스트 | MHXX 위치 |
|---|---|---|
| **시야각** | 확인됨 | 카메라 투영 3곳 `0x21bb60`, `0x21bbac`, `0xae8ec0` |
| **렌더링 해상도** | 확인 필요 | 렌더 크기 `0xdb174c`, 2D 화면 크기 `0xdb1760` |
| **화면비** | 테스트 안 함 | 카메라 투영과 같은 곳 |
| **FSR** | 확인됨 | 카메라 `0x21bb30`/`0x21bb4c`, 컷신 카메라 `0xb4c428`/`0xb4c9bc`, 보상 화면 사진 `0xa64270` |
| **NPC 표시 거리** (표시 거리) | 테스트 안 함 | `0x8b7cdc`, `0x8b611c` |

## 고프레임 보정

30fps 기준으로 만들어진 게임 동작이 고프레임에서도 원작처럼 되게 함. 전부 확인됨.

- **몬스터 이동 판정**: 고프레임에서 몬스터가 거리를 못 좁히고 옆으로 빠지던 문제 (`0x2c2d94`, `0x2c2e8c`)
- **몬스터 점프**: 아오아시라·우루쿠스스·볼보로스 뛰어오르기, 볼보로스 몸통 누르기, 진오우거 (26곳)
- **동시 입력 허용 시간**: X+A 같은 버튼 조합 (`0x479cc8`)
- **HUD 버프 아이콘 순환 속도** (`0x82ba2c`, `0x82bc00`)

## 편의 기능

- **마을 이벤트 넘기기**: 새 시설 소개 같은 카메라 이벤트를 A로 빨리 넘김 (`0xb5ab7c`). 확인됨

## 찾은 방법

MHGU Recomp가 MHGU 1.4.0에서 고치던 명령어를 MHXX 1.5.1 실행 파일에서 같은 명령어와 같은 메모리 위치로 찾고, 주변 코드가 MHGU 기록과 맞는지 대조함. 리컴파일 시 45곳 모두 적용됨.

- 멀티 테스트

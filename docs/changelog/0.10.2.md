# MHXX Recomp 0.10.2

> 멀티플레이는 같이 하는 사람 모두 **0.10.2**로 업데이트해 주세요. 0.10.1 이하와는 같이 플레이할 수 없습니다. 런처를 켜면 업데이트 안내가 뜹니다.

제보해 주신 버그를 고친 업데이트입니다. 디시, 구글 폼으로 알려 주신 분들 감사합니다.

## 고친 점

- **HUD 옆 1픽셀 선**
  - 0.10.0부터 지도, 무기 아이콘, 시계, 소모품 선택창(LB), 아이템 사용 버튼 왼쪽에 얇은 선이 보이던 것을 고쳤습니다.
  - 0.10.0의 게임 버튼 아이콘 기능이 HUD 그림을 바꿔 넣을 때, 원래 게임에 없던 축소본까지 만들어 넣어서 옆 그림이 섞여 보였습니다.

- **21:9 등 넓은 화면에서 동반자 창이 왔다 갔다 하던 것**
  - 동반자(오트모) 서포트 행동·스킬 장착 화면에서 빈 칸(------)을 고르면 가운데 창이 반대쪽 끝으로 옮겨 가던 것을 고쳤습니다.
  - 설명창이 생기고 사라져도 창이 처음 자리에 그대로 있습니다.

- **고해상도 텍스처를 만들다 드라이버가 재시작되던 것**
  - 일부 그래픽카드에서 몬스터 업스케일링 중 화면이 검게 변하고 드라이버가 재시작되던 문제에 대비했습니다.
  - 그림을 작은 조각으로 나눠 처리해서, 그래픽카드가 한 번에 오래 붙잡혀 있지 않게 했습니다. 작성자 PC(RTX 3070 Ti)에서 몬스터 전체 약 2분으로 속도는 그대로입니다.
  - 드라이버가 재시작되더라도 런처의 버튼이 사라지지 않고 다시 나옵니다.
  - 그래도 같은 문제가 나면 오버클럭·언더볼트를 끄거나 안정적인 드라이버 버전으로 바꿔 보시고, 아래 문제 보고 파일을 보내 주세요.

## 바뀐 점

- **문제 보고가 더 자세해졌습니다**
  - 런처 **도구 → 문제 보고** 파일에 바로 전 런처 실행 기록(`launcher.prev.log`)이 같이 들어갑니다. 문제가 난 뒤 런처를 다시 켜서 만들어도 그때 기록이 남아 있습니다.
  - 고해상도 텍스처를 만드는 과정도 기록에 남아서, 어느 텍스처에서 멈췄는지 알 수 있습니다.

- **설명서 정리**
  - [플레이 매뉴얼](../manual.md)을 0.10 기준으로 정리했습니다. 맨 위에 빨리 시작하기와 목차가 있고, 음성 채팅, 게임 버튼 아이콘, 영문판 플러그인, 백그라운드 FPS 설명이 들어갔습니다.

## 구글 폼 건의 답변

- **결정/취소(A/B) 바꾸기**: 지금도 F1 → 조작 → 컨트롤러 버튼에서 A와 B를 서로 바꿀 수 있습니다. 다만 사냥 중 조작도 같이 바뀝니다. 메뉴에서만 바꾸는 옵션은 검토 중입니다.
- **UI 크기 조절**: 검토하겠습니다.
- **Damage Display(데미지 숫자)**: 0.10.0부터 됩니다. 영문판 Forge 플러그인 일부를 그대로 쓸 수 있고, 넣는 방법은 설명서 6장에 있습니다.
- **글꼴 바꾸기**: 게임 글꼴은 한글패치가 글자를 그림으로 그려 넣은 방식이라 바꾸려면 작업이 커서 당장은 어렵습니다. 나중에 검토하겠습니다.
- **다운로드(DL) 이벤트 퀘스트가 깨지거나 번역이 안 됨**: 포팅 문제가 아니라, 세이브에 저장된 이벤트 퀘스트는 한글패치가 바꾸지 않는 부분이라 그렇습니다(번역팀 확인). 번역된 퀘스트 파일을 쓰는 방법을 검토하고 있습니다.

# MHXX Recomp 0.7

0.6 이후 추가된 것 (2026-11-08). 런처에서 고해상도 텍스처 만들기. 빌드: `make`, `sh tools/texextract/build.sh`, `sh tools/launcher/build.sh`, 그 다음 `make dist VERSION=0.7 ANDROID_DIST=`.

## 런처: 고해상도 텍스처 — 새로 추가

고해상도 텍스처 팩은 게임 그림을 가공한 것이라 배포판에 넣을 수 없습니다. 대신 런처가 **사용자 PC에서 사용자의 게임 파일로** 만듭니다. 0.4의 `upscale.py`가 하던 일을 파이썬 없이 런처 안에서 합니다.

| 기능 | 테스트 | 설명 |
|---|---|---|
| **고해상도 텍스처 화면** | 화면 확인 | 런처 왼쪽 **고해상도 텍스처** 버튼(게임 파일 설치 옆). 게임 실행 중에는 막힘 |
| **고르기** | 확인 | 방어구·무기·오토모 장비 4배(128 → 512, 256 이하만), 몬스터 2배(1024 → 2048, 1024 이하만) |
| **텍스처 뽑기** | 몬스터 아카이브(em001_00)로 확인 | `mhxx-texextract`를 런처가 실행(창 없이). 모드 폴더의 romfs(한글패치)도 같이 넘김. 결과는 `textures\extracted`, 한 번 뽑으면 다음부터 건너뜀(`.complete`) |
| **업스케일 프로그램 받기** | Windows에서 확인 전 | `realesrgan-ncnn-vulkan`이 없으면 GitHub 릴리스(v0.2.5.0, 약 40MB)에서 받아 `realesrgan` 폴더에 풂. 업데이터의 HTTPS(WinHTTP)와 zip 코드 사용 |
| **AI 업스케일** | 대역 프로그램으로 확인 (실제 realesrgan은 확인 전) | 컬러 텍스처는 RGB로 realesrgan(`realesrgan-x4plus-anime`, 4배)에 200개씩 넘기고, 2배면 Lanczos로 줄임. 투명도는 원본에서 따로 Lanczos로 키워 다시 합침 |
| **노멀맵·마스크** | 확인 | Lanczos 확대(Pillow의 Lanczos와 평균 차이 0.2/255) |
| **진행과 중지** | 화면 확인 | 단계, 진행 막대, 개수, 남은 시간. **중지**하면 realesrgan도 멈추고, 만든 것은 남아 다음에 이어서 함 |
| **배포판** | 확인 | zip에 `mhxx-texextract.exe`가 들어감(`tools/dist.py`). 없으면 "sh tools/texextract/build.sh first"로 멈춤 |

결과는 기존과 같은 `textures\load\<키>.png`. 게임은 다음 실행부터 읽음.

## 아직 안 된 것
- 실제 Windows에서 고해상도 텍스처 만들기 전체 확인(다운로드, realesrgan)
- 실제 게임 파일로 게임 파일 설치 확인 (0.6)
- 남은 업스케일링(영상, 맵, 소형 몬스터·이펙트·UI) — 0.5 변경 내역 참고
- 모르는 TEX 형식 4종 (24개)
- 고프레임 연타 판정, 몬스터 표적 고르기
- 체력 배율, 집회소에서 마을 퀘스트, 소형 몬스터 동기화, 긴급 퀘스트 공유, 디스코드, 보너스 콘텐츠
- 멀티 테스트

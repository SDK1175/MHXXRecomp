# MHXX Recomp 0.7

0.6 이후 추가된 것 (2026-11-08). 런처에서 고해상도 텍스처 만들기. 빌드: `make`, `sh tools/texextract/build.sh`, `sh tools/launcher/build.sh`, 그 다음 `make dist VERSION=0.7 ANDROID_DIST=`.

## 런처: 고해상도 텍스처 — 새로 추가

고해상도 텍스처 팩은 게임 그림을 가공한 것이라 배포판에 넣을 수 없습니다. 대신 런처가 **사용자 PC에서 사용자의 게임 파일로** 만듭니다. 0.4의 `upscale.py`가 하던 일을 파이썬 없이 런처 안에서 합니다.

| 기능 | 테스트 | 설명 |
|---|---|---|
| **고해상도 텍스처 화면** | 확인됨 | 런처 왼쪽 **고해상도 텍스처** 버튼(게임 파일 설치 옆). 게임 실행 중에는 막힘 |
| **고르기** | 확인 | 방어구·무기·오토모 장비 4배(128 → 512, 256 이하만), 몬스터 2배(1024 → 2048, 1024 이하만) |
| **텍스처 뽑기** | 확인됨 | `mhxx-texextract`를 런처가 실행(창 없이). 모드 폴더의 romfs(한글패치)도 같이 넘김. 결과는 `textures\extracted`, 한 번 뽑으면 다음부터 건너뜀(`.complete`) |
| **업스케일 프로그램 받기** | 확인됨 | `realesrgan-ncnn-vulkan`이 없으면 GitHub 릴리스(v0.2.5.0, 약 40MB)에서 받아 `realesrgan` 폴더에 풂. 업데이터의 HTTPS(WinHTTP)와 zip 코드 사용 |
| **AI 업스케일** | 확인됨 | 컬러 텍스처는 RGB로 realesrgan(`realesrgan-x4plus-anime`, 4배)에 200개씩 넘기고, 2배면 Lanczos로 줄임. 투명도는 원본에서 따로 Lanczos로 키워 다시 합침 |
| **노멀맵·마스크** | 확인 | Lanczos 확대(Pillow의 Lanczos와 평균 차이 0.2/255) |
| **진행과 중지** | 확인됨 (중지 후 이어하기) | 단계, 진행 막대, 개수, 남은 시간. **중지**하면 realesrgan도 멈추고, 만든 것은 남아 다음에 이어서 함 |
| **배포판** | 확인 | zip에 `mhxx-texextract.exe`가 들어감(`tools/dist.py`). 없으면 "sh tools/texextract/build.sh first"로 멈춤 |

결과는 `textures\load\gear\<키>.png`(장비)와 `textures\load\monsters\<키>.png`(몬스터). 예전처럼 `textures\load`에 바로 있던 팩은 만들기를 실행할 때 알맞은 폴더로 옮겨짐. 게임은 다음 실행부터 읽음.

## 텍스처 팩 가져오기 — 새로 추가

| 기능 | 테스트 | 설명 |
|---|---|---|
| **다른 폴더에서 텍스처 팩 가져오기** | 확인됨 | 고해상도 텍스처 화면 아래 버튼. 같은 PC의 다른 게임 폴더(이전 버전 등)를 고르면 그 팩을 이 폴더로 복사해서 다시 만들 필요가 없음. 게임 폴더, 그 `textures\load`, 팩 폴더 어느 것을 골라도 됨 |
| **분류 정리** | 확인 | 폴더가 나뉘기 전 팩(`textures\load`에 바로 있는 그림)은 뽑기 목록을 보고 `gear`/`monsters`로 넣음. 목록은 `textures\extracted\index.txt`(그쪽이나 이쪽)와, 고른 게임 폴더 옆이나 두 단계 위까지의 폴더에 있는 mhxx-texextract의 `index.txt`(직접 뽑았던 `textures_all2` 등)를 찾아 씀. 모르는 그림은 그대로 맨 위에(장비만·장비+몬스터일 때 쓰임) |
| **뽑은 텍스처도 같이** | 확인 | 그쪽에 다 뽑아 둔 텍스처(`textures\extracted`)가 있고 이쪽엔 없으면 같이 복사해서, 나중에 만들기를 해도 뽑기 단계를 건너뜀 |
| **이어하기·오류** | 확인 | 이미 같은 크기로 있는 파일은 건너뜀. 같은 폴더를 고르거나 팩이 없는 폴더면 이유를 알려 줌. 중지 가능 |

팩은 본인 PC 안에서만 복사합니다(배포판에는 들어가지 않음).

## 고해상도 텍스처 사용 설정 — 새로 추가

저사양 PC를 위해 어떤 고해상도 텍스처를 쓸지 고를 수 있습니다. 그래픽카드 메모리는 프로그램이 직접 재서 알려 줍니다.

| 기능 | 테스트 | 설명 |
|---|---|---|
| **설정** | 빌드 확인 | 그래픽 및 오디오 → **고해상도 텍스처**: 자동(추천) / 꺼짐 / 장비만 / 장비+몬스터. 재시작 필요(`*`)라 런처에도 나옴. `[Graphics] TexturePack = Auto/Off/Gear/All` |
| **그래픽카드 메모리 자동 측정** | 게임: 빌드 확인, 런처: 가짜 값으로 화면 확인 | 게임은 Vulkan(쓰는 그래픽카드의 가장 큰 전용 메모리), 런처는 Windows DXGI(전용 메모리가 가장 큰 그래픽카드)로 잼. 항목 설명에 "이 PC의 그래픽카드: 이름, 메모리 N GB. 추천: …"을 보여 주고, 자동이면 이름 옆에 무엇이 골라졌는지 표시. 런처의 고해상도 텍스처 화면에도 표시 |
| **추천 기준** | | 전용 메모리 1.5GB 미만: 꺼짐, 3.5GB 미만: 장비만, 그 이상: 장비+몬스터. 내장 그래픽(시스템 메모리 공유): 1.5GB 이상이면 장비만, 아니면 꺼짐. 측정 실패: 장비만 |
| **적용** | 빌드 확인 | 게임이 팩을 읽을 때 꺼짐이면 전부 건너뛰고, 장비만이면 `monsters` 폴더를 건너뜀. `log.txt`에 `[texpack] texture pack: gear (auto) (graphics memory 8.0 GB)`처럼 남음 |

# 다음 업데이트에 넣을 것 (릴리즈 때 버전 이름으로 바꿈)

## 고친 점

- **Faster Field Hunter의 "모두 채집"(Gather all at once)이 동작합니다.** 채집 포인트를 A 한 번으로 남은 횟수만큼 한 번에 캡니다. (영문판 플러그인이 덥크에서 다른 칸의 값을 읽던 것을 포트가 맞춰 줌)

## 새 기능

- **긴급 퀘스트 클리어 공유:** 다른 사람이 올린 긴급 퀘스트를 같이 깨면, 내가 그 퀘스트를 해금했을 때 나도 클리어로 칩니다 (원래 게임은 올린 사람만). F1 → 멀티플레이 → "긴급 퀘스트 클리어 공유" (기본 켜짐). 내 세이브만 바뀌고, 다른 사람에게는 영향이 없습니다.

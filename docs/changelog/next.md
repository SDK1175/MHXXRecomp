# 다음 업데이트에 넣을 것 (릴리즈 때 버전 이름으로 바꿈)

## 새 기능

- **한글 채팅·이름 입력:** 게임의 채팅이나 이름 입력 칸에 키보드로 한글을 쓸 수 있습니다 (윈도우 한글 입력기, 한/영 키로 전환). 조합 중인 글자도 입력 칸에 바로 보입니다. 덥크 한글 패치가 쓰는 방식으로 바꿔 넣기 때문에, 한글 패치를 쓰는 다른 사람에게도 한글로 보입니다. 한글 패치에 없는 글자(ㅋㅋ 같은 자음·모음만 쓴 글자, 똠·햏 같은 드문 글자)는 ?로 바뀝니다.

## 고친 점

- **멀티 R3 스킵 안내:** 동의 현황("동의: 1 / 2명")이 R3를 누른 사람만이 아니라 **모두에게** 보이고, 모두 동의하거나 귀환 대기가 끝날 때까지 화면에 계속 남습니다 (와일즈처럼).

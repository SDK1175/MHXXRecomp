# 다음 업데이트에 넣을 것 (릴리즈 때 버전 이름으로 바꿈)

## 0.11.0 후보 (기능)

- **이명 퀘스트 클리어 공유:** 긴급 퀘스트처럼, 이명(이상) 특수 허가 퀘스트도 멀티로 깨면 같이 간 사람 모두 클리어 처리. 원래는 퀘스트를 올린 사람만 클리어됨. (GitHub 이슈 #3, ZuvuBR: 덥크로 하는지 확인 중)
  - 이명 퀘스트는 등급(특수 허가 단계) 해금이 걸려 있어 긴급 퀘스트보다 영향이 큼: 단계를 건너뛰지 않게 할지 정할 것.
- **부위 경직·파괴치 연동 옵션 (이슈 #4, Koyoming870):** `[Monster HP]`에 `ScaleStagger`(기본 Off). 켜면 `nando_row()`가 `column == 2` 행의 `+0x0c`(부위 경직치 배율, 부위 파괴·꼬리 절단 공통)도 HP와 같은 배율로. 공격력·방어·스태미나·상태 이상은 그대로. 멀티는 방장 설정을 `SYNC_MAGIC 0xE6` 패킷의 빈 바이트 `m[1]`로 (이슈의 제안). 로그는 `column == 0`에서만.
- **고프레임 컷인 뒤 탑뷰 카메라 고정 (이슈 #5, Koyoming870):** 업스트림 MHGU Recomp `runtime/hle/stageview.c`를 가져오기. 이슈의 MHXX 1.5.1 주소(헬퍼 `0x5d30a8`, 패치 `0x5d312c` = `0xE5940018`, 건너뛸 곳 `0x5d327c`)는 직접 다시 확인할 것.

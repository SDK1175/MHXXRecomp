# 다음 업데이트에 넣을 것 (릴리즈 때 버전 이름으로 바꿈)

## 새 기능

- **퀘스트가 끝나면 R3로 바로 귀환:** 퀘스트가 끝나면(클리어·실패) 화면에 안내가 뜨고, R 스틱 클릭(키보드: Alt)을 누르면 귀환 대기 시간(20초)과 마무리 화면을 건너뛰고 바로 결과 화면으로 갑니다. F1 → 기타 → "퀘스트 종료 후 R3로 바로 귀환"으로 끌 수 있습니다.
  - **멀티에서는 전원 동의:** 퀘스트에 참가한 헌터가 **모두** R3를 누르면 다 같이 바로 귀환합니다. 한 명이라도 안 누르면 평소처럼 기다립니다. 기본으로 켜져 있고, F1 → 기타 → "멀티에서도 R3 스킵 (전원이 눌러야 함)"으로 끌 수 있습니다(끈 사람이 있으면 스킵되지 않음). 아직 실제 멀티로 확인하지 못했으니, 써 보시고 결과를 디시 댓글이나 [이슈 탭](https://github.com/SDK1175/MHXXRecomp/issues)에 알려 주세요.

## 고친 점

- **고프레임(60fps 이상)에서 몬스터가 둥지에서 잠을 안 자던 문제:** 전투 중 차오른 몬스터의 "헌터 눈치채기" 수치가 고프레임에서는 줄어들지 않아, 도망가서 자러 간 몬스터가 도착하자마자 헌터를 눈치채고 두리번거리다 다시 떠나던 문제를 고쳤습니다. (영문판 포트의 수정을 덥크에 옮김)
- **고프레임에서 듀라무보로스의 제자리 회전이 너무 빠르던 문제:** 돌진 끝의 긴 제자리 회전이 240fps에서는 몇 바퀴씩 돌던 것을 30fps와 같은 각도로 맞췄습니다. (영문판 포트의 수정을 덥크에 옮김)

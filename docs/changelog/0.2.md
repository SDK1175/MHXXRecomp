# MHXX Recomp 0.2

0.1 이후 추가된 것 (2026-11-06). 게임 코드를 다시 리컴파일하지 않고 런타임만 바꾼 버전이라 `make gen` 없이 `make`로 빌드됨.

## 새 기능

### 컨트롤러 버튼 매핑
F1 → 조작 → **컨트롤러 버튼**
- 스위치 버튼 16개(A·B·X·Y, L·R·ZL·ZR, +·−, 십자키 4방향, 스틱 누르기 2개)마다 컨트롤러의 어떤 버튼으로 누를지 지정
- **버튼 눌러서 지정**: 항목을 고른 뒤 컨트롤러에서 원하는 버튼을 누르면 인식
  - 고를 때 누른 버튼은 한 번 뗀 뒤부터 받음 (잘못 들어가지 않게)
  - 5초 안에 안 누르거나 Esc, 마우스로 취소 누르면 취소
- **기본**(원래 버튼), **없음**(안 씀)도 선택 가능
- 같은 버튼을 두 곳에 지정하면 빨간색으로 경고
- 버튼 이름은 연결된 컨트롤러 종류대로 표시 (듀얼센스: Cross/L1…, 프로콘: B/ZL…, 엑스박스: A/LB…)
- 트리거(LT/RT), 뒷버튼(패들 1~4), 터치패드, 캡처/공유 버튼도 지정 가능
- 두 버튼을 서로 바꾸려면 둘 다 지정해야 함
- F1 메뉴 안에서는 항상 원래 버튼으로 움직임 (잘못 지정해도 컨트롤러로 되돌릴 수 있게)
- `mhgurecomp.ini`의 `[Controller]` 섹션에 저장

### 편의 기능 (MHGU Recomp 기능을 MHXX 주소로 옮김)
| 기능 | 설명 | MHXX 주소 |
|---|---|---|
| **로딩 가속** | 게임 데이터 압축 해제를 빠른 코드로 바꿔 로딩 단축 | `0x1417520`, `0x1416fac` |
| **마우스 시점** | 퀘스트 중 마우스로 카메라를 바로 돌림 (Esc로 마우스 풀기) | `0x224d7c` |
| **휠 아이템바** | 사냥 중 L 없이 마우스 휠 한 칸에 아이템 한 칸 | `0x4f4e98` 외 3개 |

세 기능 모두 MHGU의 해당 함수를 MHXX 실행 파일에서 찾아 연결함. 압축 해제 코드는 MHGU와 같은 zlib 1.2.8이고, 카메라와 플레이어의 메모리 구조도 MHGU와 같은 것을 확인함.

### 창 X 버튼으로 종료
- X를 누르면 "게임을 종료할까요?" 확인창이 뜸
- 3초 안에 X를 한 번 더 누르면 바로 종료
- 설정 메뉴가 꺼져 있는 상태면 바로 종료
- 0.1의 "X 버튼으로 안 꺼짐" 문제 해결

### F1 설정 메뉴 한국어
- 언어에 **한국어** 추가. 새로 만드는 설정 파일은 기본이 한국어
  - 0.1을 쓰던 경우: F1 → 언어 → 한국어로 바꾸거나 `mhgurecomp.ini`에서 `Language = Korean`
- 탭 이름, 설정 항목, 선택지, 확인창·오류 문구, 허브 서버 알림, 항목 설명글까지 번역 (약 440개 문구)
- MSAA, FSR, Xbox 같은 고유 이름은 영어로 둠
- 한글 글꼴: 윈도우의 **맑은 고딕**을 불러와 씀 (배포판에 글꼴 파일 없음)
  - 다른 글꼴을 쓰려면 게임 폴더에 `fonts\menu.ttf`로 넣기
  - 리눅스·안드로이드는 Noto Sans CJK나 나눔고딕을 찾아 씀
  - 어떤 글꼴을 불러왔는지 `log.txt`의 `[overlay] Hangul font` 줄에 남음

## 테스트 상태

| 항목 | 상태 |
|---|---|
| 컨트롤러 버튼 매핑 | 확인됨 |
| 로딩 가속, 마우스 시점, 휠 아이템바, X 버튼 종료 | 확인됨 |
| F1 메뉴 한국어 | 빌드 후 확인 필요 |

## 아직 안 된 것

- 고프레임 게임 동작 보정 (몬스터 경직, 점프, 연타 판정, 공격 판정 간격 등)
- 해상도·화면비·시야각, FSR 카메라 흔들림 보정
- 체력 배율, 집회소에서 마을 퀘스트, 소형 몬스터 동기화, 긴급 퀘스트 공유, 디스코드 상태 표시, 보너스 콘텐츠
- 멀티: 로컬 통신 집회소를 인터넷으로 잇는 기능은 그대로 들어 있으나 MHXX에서 아직 테스트 안 함. 기본 허브 서버 없음

# MHXX Recomp 0.10.4

> 멀티플레이는 같이 하는 사람 모두 **0.10.4**로 업데이트해 주세요. 0.10.3 이하와는 같이 플레이할 수 없습니다. 런처를 켜면 업데이트 안내가 뜹니다.

## 바뀐 점

- **게임이 튕기면 런처가 문제 보고를 권합니다**
  - 게임이 비정상적으로 종료되면(튕김, 강제 종료) 런처 왼쪽에 안내와 **문제 보고** 버튼이 나옵니다. 누르면 도구 → 문제 보고가 바로 열립니다.
  - 문제 보고 파일에는 방금 실행의 기록이 들어갑니다. 어디로도 자동으로 보내지 않으니, 깃허브 이슈에 직접 올려 주세요.
  - 메뉴로 종료하거나 런처로 나가는 등 정상적으로 끄면 나오지 않습니다.
- **런처 창이 조금 커졌습니다** (1280×900). 화면이 작으면 화면에 맞춰 줄어듭니다.
- **영문판 플러그인 호환 목록 갱신**: 사용자 제보로 UIScale(HUD 크기 조절), Confirm on X(메뉴 결정/취소 바꾸기), MHGU DPS Meter, Better Skill Info가 동작하는 것을 확인했습니다.
  - https://github.com/SDK1175/MHXXRecomp/blob/mhxx/docs/gu-plugins.md

## 건의 답변

- **월드식 조작(달리기와 무기 특수 기술을 다른 트리거로)**: 영문판 플러그인 **Sprint/Weapon Trigger Split**(Katt404, KatLib 필요)이 이 기능을 합니다. 덥크에서는 아직 확인 전이니, 써 보신 분은 결과를 알려 주세요.

# MHXX Recomp 0.10.14

## 새 기능

- **대장간 모드 지원:** 대장간 무기·방어구 목록을 파생 트리와 상세 카드로 보여 주는 모드 **MHXX Smithy Tree**가 이번 버전부터 동작합니다. 모드는 [따로 배포](https://github.com/SDK1175/mhxx-smithy-tree/releases)하며, **0.10.14 이상**이 필요합니다.
- **플러그인용 기능 추가:** 모드를 만드는 분들을 위해 플러그인이 쓸 수 있는 기능을 늘렸습니다.
  - 플러그인이 자기 화면을 띄우는 동안 컨트롤러 입력을 가져오고, 끝나면 게임에 돌려줄 수 있습니다. 돌려줄 때 누르고 있던 버튼이 게임에 잘못 들어가지 않습니다.
  - 플러그인 화면에서 게임의 버튼을 대신 눌러 줄 수 있습니다(예: 확인 창의 "예"를 게임의 A로).
  - 게임 파일 안의 아이콘 같은 텍스처를 읽어서 플러그인 화면에 그릴 수 있습니다. 모드에 게임 그림을 넣어 배포할 필요가 없습니다.
  - 게임이 불러온 데이터(무기·방어구 표, 이름 등)를 찾아 읽을 수 있고, 한글 패치의 글자를 한글로 바꿔 읽을 수 있습니다.

## 고친 점

- **모드 로딩 시간:** 텍스처나 아카이브가 없는 모드(플러그인만 있는 모드)를 넣었을 때, 게임 시작 때 1분 가까이 걸리던 아카이브 검사를 건너뜁니다.

## 영문판 모드 호환

- 이번 버전부터 **데이터 모드는 하나씩 맞추지 않고, 플러그인 호환만** 이어 갑니다.
- **No Flexing Mod:** 동작합니다(사용자 확인).
- **GU CraftWheel:** 영문판 ＋ 메뉴 구조에 맞춰 만들어진 모드라 덥크에서는 동작하지 않습니다. 넣지 마세요.
- **Modern Weapon Trees:** 영문판 대장간 화면에 맞춰 만들어진 모드라 동작하지 않습니다. 비슷한 기능은 위의 MHXX Smithy Tree로 쓰실 수 있습니다.

## 알아 두기

- 멀티는 같이 하는 사람 모두 **0.10.14**여야 합니다.
- 인터넷 통신(허브 서버)을 쓰면 서버 관리자에게 접속 IP와 닉네임이 보입니다. 이 정보는 트롤·신고 처리(밴)에만 쓰고, 접속 기록은 3일 뒤 자동으로 지워집니다. 원하지 않으면 허브 서버를 끄고 로컬 통신이나 라드민으로 하시면 됩니다.

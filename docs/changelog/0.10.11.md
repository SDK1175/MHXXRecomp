# MHXX Recomp 0.10.11

## 새 기능

- **타이틀 화면에서 B로 종료:** 타이틀의 메인 메뉴에서 B를 누르면 창을 닫을 때(Alt+F4)처럼 종료할지 묻습니다. 데이터 선택·옵션 화면에서는 원래대로 뒤로 가기입니다. F1 → 기타 → "타이틀 메뉴에서 B로 종료"로 끌 수 있습니다.
- **F1 메뉴가 내 패드 버튼 설정을 따릅니다:** F1 → 조작에서 A·B·X·Y를 바꿔 두셨다면, F1 메뉴의 선택·뒤로·저장·되돌리기도 그 배치대로 동작하고 버튼 표시도 맞게 바뀝니다. (A나 B를 버튼 없음으로 둔 경우에는 메뉴를 쓸 수 있게 원래 배치를 유지합니다)
- **긴급 퀘스트 클리어 공유:** 다른 사람이 올린 긴급 퀘스트를 같이 깨면, 내가 그 퀘스트를 해금했을 때 나도 클리어로 칩니다 (원래 게임은 올린 사람만). F1 → 멀티플레이 → "긴급 퀘스트 클리어 공유" (기본 켜짐). 내 세이브만 바뀌고, 다른 사람에게는 영향이 없습니다.
  - 아직 멀티로 직접 확인하지 못했습니다. 다른 사람이 올린 긴급 퀘스트를 같이 깨 보셨다면, 클리어로 쳐졌는지 디시 댓글이나 [이슈 탭](https://github.com/SDK1175/MHXXRecomp/issues)에 알려 주세요.

## 고친 점

- **Faster Field Hunter의 "모두 채집"(Gather all at once)이 동작합니다.** 채집 포인트를 A 한 번으로 남은 횟수만큼 한 번에 캡니다. 받는 곳과 설치법: [영문판 플러그인 호환 목록](../gu-plugins.md)

## 알아 두기

- 멀티는 같이 하는 사람 모두 **0.10.11**이어야 합니다.
- 인터넷 통신(허브 서버)을 쓰면 서버 관리자에게 접속 IP와 닉네임이 보입니다. 트롤·신고 처리(밴)에만 쓰고, 접속 기록은 3일 뒤 자동으로 지워집니다. 원하지 않으면 허브 서버를 끄고 로컬 통신이나 라드민으로 하시면 됩니다.

# MHXX Recomp 0.10.7

## 새 기능

- **한글 글꼴이 선명해집니다**
  - 한글 패치를 쓰면, 한글을 **페이퍼로지** 글꼴(영미판 한글 패치와 같은 글꼴)로 2배 해상도로 다시 그립니다.
  - 글자 위치와 간격은 한글 패치 그대로입니다. 한글 패치 파일은 바꾸지 않습니다.
  - F1 → 화면 → **한글 글꼴**에서 "한글 패치 그대로"로 되돌릴 수 있습니다. (다음 실행부터 적용)
  - 글꼴: [Paperlogy](https://github.com/Freesentation/paperlogy) (PT&, 이주임), SIL Open Font License 1.1

## 바뀐 점

- **HUD 위치 21:9 / 32:9 / 양 끝은 실험적 기능입니다**
  - XX는 화면 종류가 너무 많아서, 모냥 원정 지도처럼 HUD가 깨지는 화면이 있습니다. 화면이 이상하면 HUD 위치를 16:9(기본값)로 바꾸세요. 게임 화면은 21:9 그대로 넓게 나옵니다.

## 알아 두기

- 멀티는 같이 하는 사람 모두 **0.10.7**이어야 합니다.
- 인터넷 통신(허브 서버)을 쓰면 서버 관리자에게 접속 IP와 닉네임이 보입니다. 트롤·신고 처리(밴)에만 쓰고, 접속 기록은 3일 뒤 자동으로 지워집니다. 원하지 않으면 허브 서버를 끄고 로컬 통신이나 라드민으로 하시면 됩니다.

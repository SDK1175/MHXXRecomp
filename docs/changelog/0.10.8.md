# MHXX Recomp 0.10.8

## 새 기능

- **영문판(MHGU)용 텍스처 모드를 그대로 넣을 수 있습니다**
  - 영문판 모드(예: Xbox Controller Layout, Monster Weakness Icons)를 `mods\모드이름\romfs\`에 넣으면, 게임을 켤 때 덥크 위치로 옮겨 넣습니다.
  - 모드가 실제로 바꾼 그림만 들어갑니다. 메뉴 그림은 모드가 그린 부분만 얹어서, 같은 그림의 한글(한글 패치)은 그대로 남습니다.
  - 처음 켤 때 한 번 만들어 두고, 다음부터는 바로 씁니다. 자세한 내용: [영문판 플러그인 호환 목록](../gu-plugins.md)
- **MHGU Utility(Hunter's Compendium) 플러그인이 동작합니다**
  - 아이템·무기 트리·방어구·위시리스트·스킬 조합·퀘스트 추천·채집 지도 아이콘까지 모두 동작합니다.
  - 플러그인 창을 마우스로 쓸 수 있고, 검색창에 빠르게 쳐도 글자가 순서대로 들어갑니다.
  - 플러그인의 패드 버튼 표시가 F1에서 바꾼 버튼 설정을 따릅니다.

## 바뀐 점

- 플러그인 창이 열려 있을 때 마우스 포인터가 보이고, 클릭이 게임 화면 터치로 같이 들어가지 않습니다.
- 플러그인 창(ImGui)을 그리는 부담이 줄었습니다.
- KatSmithy 플러그인은 덥크에서 게임이 꺼지므로 호환 목록에 "안 됨"으로 적었습니다.

## 알아 두기

- 멀티는 같이 하는 사람 모두 **0.10.8**이어야 합니다.
- 인터넷 통신(허브 서버)을 쓰면 서버 관리자에게 접속 IP와 닉네임이 보입니다. 트롤·신고 처리(밴)에만 쓰고, 접속 기록은 3일 뒤 자동으로 지워집니다. 원하지 않으면 허브 서버를 끄고 로컬 통신이나 라드민으로 하시면 됩니다.

## 테스트 환경

Windows 11, AMD 라이젠 7 5700X3D, RTX 3070 Ti (8GB), 메모리 32GB

# MHXX Recomp 0.8 (작업 중 · 초안)

> **아직 빌드 전입니다.** 0.8에서 할 일을 미리 적어 둔 계획이며, 빌드할 때 실제 내용으로 고칩니다.

목표: **멀티플레이가 제대로 되고, 라드민 같은 가상 LAN 없이도 할 수 있게.** 음성 채팅은 0.9에서 합니다.

## 1. 기본 멀티 확인

| 확인할 것 | 상태 |
|---|---|
| 라드민 VPN으로 방 만들기 / 들어가기 | 테스트 전 |
| 집회소 같이 있기, 퀘스트 같이 출발 | 테스트 전 |
| 큰 몬스터 위치·움직임 동기화, 공격 판정, 아이템 | 테스트 전 |
| 퀘스트 완료와 보상, 한 명이 수레 갔을 때 | 테스트 전 |
| 30fps와 60fps 이상(고프레임 보정)에서 각각 | 테스트 전 |

양쪽 `log.txt`(`[ldn]` 줄)를 모아 문제를 찾습니다.

## 2. 멀티 문제 수정

- 테스트에서 나온 문제
- 포크 뒤 원본 MHGU Recomp에 들어간 멀티 수정 중 MHXX에도 필요한 것 가져오기

## 3. 방 찾기 개선

- 지금은 같은 LAN의 방을 브로드캐스트 한 번으로 찾아서, 라드민·하마치 같은 가상 랜카드로는 안 나가는 경우가 있음(그럴 땐 F1 → 네트워크 → Join에 방장의 라드민 주소 `26.x.x.x`를 넣어야 함)
- PC의 모든 네트워크에 각각 찾게 바꿔, 주소 없이도 가상 LAN 친구 방이 보이게

## 5. MHXX 전용 허브 서버

- 원본은 제작자가 운영하는 MHGU용 허브(LDN) 서버가 기본 설정되어 있지만, MHXX에서는 쓰지 않음(꺼 둠)
- 저장소의 `server/`(허브 서버 프로그램)로 MHXX 전용 서버를 띄우고 빌드 기본값에 넣기
- 그러면 포트 열기나 가상 LAN 없이 게임 안 "로컬 통신"으로 인터넷 방을 찾고 들어갈 수 있음. 매칭 키(친구끼리만 보기), IP 비공개
- 정할 것: 서버를 띄울 곳 (작성자 PC / 오라클 무료 / 서울 클라우드)

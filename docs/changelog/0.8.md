# MHXX Recomp 0.8 (작업 중 · 초안)

> **아직 빌드 전입니다.** 0.8에서 할 일을 미리 적어 둔 계획이며, 빌드할 때 실제 내용으로 고칩니다.

목표: **멀티플레이가 제대로 되고, 라드민 같은 가상 LAN 없이도 할 수 있게.** 음성 채팅은 0.9에서 합니다.

## 런처와 업데이트 (작업 완료, 빌드·테스트 전)

| 기능 | 상태 | 설명 |
|---|---|---|
| **업데이터를 런처에 합침** | 로컬 테스트 | 런처를 켜면 GitHub 최신 릴리스를 확인. 새 버전이면 **패치 노트** 탭과 "새로운 업데이트를 다운받으시겠습니까?" + 네 / 아니오. 받으면 크기·SHA-256 검사 후 설치하고 런처가 다시 켜짐. 설정, 세이브, 모드, `data`, `textures`는 건드리지 않음. 바꾼 파일은 `update\backup`에 두었다가 다음 시작에 지움(중간에 실패하면 되돌림). 런처 자신도 이렇게 교체 |
| **업데이터 프로그램 없앰** | | `mhgurecomp-updater.exe`는 더 이상 빌드·배포하지 않음. 다운로드·압축·검사 코드(`updater/`)는 런처가 씀. 업데이트하면 예전 업데이터 파일은 지워짐 |
| **버전 줄** | 화면 확인 | 런처 왼쪽에 **버전**. 새 버전을 아니오로 넘기면 "0.8 업데이트 있음"으로 바뀌고, 누르면 다시 보임 |
| **업데이트 설정** | | F1 → 메뉴 옵션 → 업데이트: 묻기 / 자동 / 끔(설명을 런처 기준으로 바꿈) |
| **게임 실행 파일 이름** | 빌드 전 | `mhgurecomp.exe` → **`MHXX Recomp.exe`**. 업데이트 뒤 예전 `mhgurecomp.exe`는 지워짐 |
| **런처 아이콘** | | 런처 전용 아이콘(남색 방패에 교차한 두 검, 직접 그린 픽셀 아트). 게임은 기존 대검 아이콘. 바탕화면 바로가기도 런처 아이콘 |
| **빌드** | | `make` 한 번으로 게임, 런처, 텍스처 뽑기까지 빌드. 배포 zip에 `version.txt` |

0.7 → 0.8은 zip을 직접 받아 덮어써야 합니다(0.7에는 업데이트 기능이 꺼져 있었음). 0.8부터는 런처가 알아서 업데이트합니다.

## 2. 멀티 문제 수정

- 테스트에서 나온 문제
- 포크 뒤 원본 MHGU Recomp에 들어간 멀티 수정 중 MHXX에도 필요한 것 가져오기

## 3. 방 찾기 개선

- 지금은 같은 LAN의 방을 브로드캐스트 한 번으로 찾아서, 라드민·하마치 같은 가상 랜카드로는 안 나가는 경우가 있음(그럴 땐 F1 → 네트워크 → Join에 방장의 라드민 주소 `26.x.x.x`를 넣어야 함)
- PC의 모든 네트워크에 각각 찾게 바꿔, 주소 없이도 가상 LAN 친구 방이 보이게

## 5. MHXX 전용 허브 서버

- 원본은 제작자가 운영하는 MHGU용 허브(LDN) 서버가 기본 설정되어 있지만, MHXX에서는 쓰지 않음(꺼 둠)
- 저장소의 `server/`(허브 서버 프로그램)로 MHXX 전용 서버를 띄우고 빌드 기본값에 넣기
- 그러면 포트 열기나 가상 LAN 없이 게임 안 "로컬 통신"으로 인터넷 방을 찾고 들어갈 수 있음. 매칭 키(친구끼리만 보기), IP 비공개
- 정할 것: 서버를 띄울 곳 (작성자 PC / 오라클 무료 / 서울 클라우드)

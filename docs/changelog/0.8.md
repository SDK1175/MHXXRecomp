# MHXX Recomp 0.8

런처가 업데이트를 맡고, 세이브 백업·모드 설치·PC 검사 같은 도구가 생겼습니다.

> **0.7을 쓰시던 분은 이번 한 번만** 0.8 zip을 받아 기존 폴더에 덮어써 주세요(0.7에는 업데이트 기능이 꺼져 있었습니다).
> 다음 업데이트부터는 런처가 알려 주고 설치까지 합니다. 설정, 세이브, 모드, 게임 파일, 텍스처는 그대로 남습니다.

## 자동 업데이트

- 런처를 켜면 새 버전이 있는지 확인합니다. 있으면 **패치 노트**와 함께 "새로운 업데이트를 다운받으시겠습니까?"가 뜹니다.
- **네**를 누르면 받아서 검사(크기, SHA-256)한 뒤 설치하고 런처가 다시 켜집니다. 설치 중 문제가 생기면 원래대로 되돌립니다.
- **아니오**를 누르면 넘어가고, 왼쪽 **버전** 줄의 "업데이트 있음"을 누르면 다시 볼 수 있습니다.
- F1 → 메뉴 옵션 → **업데이트**: 묻기(기본) / 자동 / 끔.
- 따로 있던 업데이터 프로그램(`mhgurecomp-updater.exe`)은 런처에 합쳐져 없어졌습니다.

## 도구

런처 왼쪽 아래 **도구** 버튼(종료 옆).

| 탭 | 내용 |
|---|---|
| **세이브 백업** | **지금 백업하기**로 세이브를 게임 폴더의 `backups\`에 날짜별로 보관하고, 언제든 **복원**할 수 있습니다(복원 전에 지금 세이브를 먼저 백업). 게임 시작 전과 업데이트 전에는 **자동 백업**(최근 10개 보관, 끌 수 있음) |
| **모드 설치** | 모드의 `.zip`을 고르면 `mods\`에 풀고 모드 목록에 바로 추가합니다. 여러 개를 한 번에 고를 수 있습니다 |
| **PC 사양** | CPU와 AVX2, 메모리, 그래픽카드, Vulkan 버전, 남은 용량. 게임이 돌아가지 않을 PC면 런처를 켤 때 미리 알려 줍니다 |
| **캐시** | 셰이더 캐시 크기와 **캐시 지우기**. 업데이트나 드라이버를 바꾼 뒤 화면이 깨지거나 시작할 때 멈추면 지워 보세요 |
| **문제 보고** | 로그, 설정, PC 사양을 zip 하나(`reports\`)로 만듭니다. 멀티 주소·매칭 키·Windows 사용자 이름은 빠집니다. 버그 제보 때 GitHub Issues에 첨부해 주세요 |

세이브 복원, 모드 설치, 캐시 지우기는 게임이 꺼져 있을 때만 됩니다.

## 그 밖에

- 게임 실행 파일 이름이 `mhgurecomp.exe`에서 **`MHXX Recomp.exe`**로 바뀌었습니다. 예전 파일은 런처가 정리합니다.
- 런처 전용 아이콘(남색 방패에 교차한 두 검). 바탕화면 바로가기도 이 아이콘을 씁니다.

# MHXX Recomp 0.9

> **멀티플레이를 하시는 분은 같이 하는 사람 모두 0.9로 업데이트해 주세요.** 0.9부터는 접속할 때 서로 버전을 확인해서, 버전이 다르면 같이 플레이할 수 없습니다(0.8.x와도 안 됩니다). 런처를 켜면 업데이트 안내가 뜹니다.

고프레임 보정, 로딩 시간 단축, 21:9 화면 수정, 런처·게임이 꺼지지 않던 문제 수정이 들어갔습니다.

## 게임

- **고프레임 보정**: 60fps 이상에서 몬스터가 노리는 대상을 바꾸는 속도가 빨라지던 것과 기절 연타 판정이 프레임에 따라 달라지던 것을 원작 30fps와 같게 맞췄습니다.
- **로딩 시간 단축**: 한글패치를 게임 파일과 맞추는 단계를 매번 하지 않고 결과를 저장해 다시 씁니다. 작성자 PC 기준 게임을 켜서 오프닝 영상까지 41초 → 10초.
- **21:9 등 넓은 화면** (HUD 위치 "양 끝")
  - 아이템 박스 창이 아이템 설명이 보일 때와 안 보일 때 왔다 갔다 하던 것
  - 길드 카드의 오른쪽 테두리가 떨어져 나가고, 페이지 숫자 자리에 검은 상자가 남던 것
  - 길드 카드 무기 사용 횟수 페이지의 그래프 아이콘·숫자가 카드 밖으로 나가던 것
- **화면비 고르기**: F1 → 화면의 화면비가 `1.78` 같은 숫자로만 나오던 것을 **자동 / 16:9 / 16:10 / 21:9 / 32:9 / 4:3 / 사용자 지정** 중에서 고르게 바꿨습니다. 21:9 모니터는 **자동**이 가장 정확합니다.
- 게임을 꺼도 가끔 작업 관리자에 남아 있던 것, 그래서 재시작이나 "런처로 돌아가기"가 안 되던 것을 고쳤습니다.
- F7~F10 키(원본에서 따라온 그래픽 디버그 기능, F9는 화면을 잠깐 멈춤)를 막았습니다.
- 로그가 15분에 3.5MB씩 쌓이던 것을 줄였습니다.

## 멀티플레이

- **버전 확인**: 버전이 다른 사람이 들어오면 방장이 거절하고, 양쪽 화면에 "방장의 버전 / 내 버전"과 업데이트 안내가 뜹니다.
- **방 찾기 개선**: 라드민 VPN·하마치 같은 가상 LAN에서 F1 → 네트워크에 방장 주소를 넣지 않아도 방이 보이도록 했습니다. (주소를 넣는 방법도 그대로 됩니다)

## 런처

- 런처를 더블클릭해도 가끔 안 켜지던 것, 닫아도 작업 관리자에 남아 있던 것을 고쳤습니다.
- 너비·높이 같은 **숫자 설정**을 클릭하면 숫자 입력 창이 뜹니다(키보드 숫자키·키패드). 런처에서 너비·높이가 바뀌지 않던 문제도 함께 고쳤습니다.
- 도구 → **모드 설치**에서 zip 말고 **7z 파일**과 **폴더**도 고를 수 있습니다. rar는 압축을 푼 뒤 폴더로 골라 주세요.
- 고해상도 텍스처 만들기의 첫 단계(텍스처 뽑기)를 여러 코어로 나눠 더 빨라졌습니다. 결과는 전과 같습니다.
- 런처가 켜지고 꺼지는 과정을 `launcher.log`에 남깁니다. 도구 → 문제 보고 zip에 함께 들어갑니다.

# MHXX Recomp 0.9 (계획 · 초안)

> **아직 작업 전입니다.** 할 일을 적어 둔 목록이며, 빌드할 때 실제 내용으로 고칩니다.

## 0.9에서 할 것

| 항목 | 내용 |
|---|---|
| **멀티 확인** | 11/9 친구와 라드민 VPN으로 테스트: 방 만들기, 입장, 15분 같이 플레이 정상 (게임 데이터는 UDP) |
| **고프레임 보정 옮기기 (필수)** ✅ | 일어판 게임 코드에서 위치를 찾아 켬: 몬스터 타겟팅 점수 갱신 `0x2bacd4`, 기절 연타 `0x47c56c`(원본과 구조·오프셋·호출 수 같음). 타겟팅 확인: 30fps와 약 145fps에서 관심 점수가 똑같이 초당 +240(헌터) / +120(오토모)씩 오름. 기절 연타는 실제로 기절했을 때 확인 예정 |
| **멀티 선택 기능 옮기기** | 원작에 없던 편의 기능이라 **기본 꺼짐**, 원하는 사람만 켬: 소형 몬스터 동기화, 긴급 퀘스트 공유 |
| **멀티 버전 확인** 🔧 | 접속할 때 서로 포팅 버전을 주고받아, 다르면 방장이 거절하고 양쪽에 "방장 버전 / 내 버전"과 "런처에서 같은 버전으로 업데이트" 안내. 0.8.x 이하와는 같이 못 함(어느 쪽이 방장이든). 개발 빌드는 경고만. 2대 테스트 전 |
| **방 찾기 개선** 🔧 | 라드민·하마치 같은 가상 LAN에서 주소(Join)를 넣지 않아도 방이 보이게: 방 찾기 신호를 기본 네트워크 하나가 아니라 PC의 **모든 네트워크**(예: 라드민 26.255.255.255)로 보냄. 친구와 테스트 전 |
| **로딩 시간 단축** ✅ | 한글패치(모드 파일 2,711개)를 게임 파일과 맞추는 단계가 매번 **약 23초** → 비교 결과를 저장해 두고 재사용해 **0.5초**. 게임 파일 준비가 24초 → 3초, 오프닝 영상까지 41초 → 10초 (작성자 PC) |
| **로그 줄이기** ✅ | 시간대 요청이 매 프레임 찍혀 15분에 7만 줄(3.5MB) → 한 번만 |
| **디버그 키 막기** ✅ | 원본에서 따라온 F7~F10(그래픽 디버그, F9를 누르면 잠깐 멈춤 등)을 평소에는 끄고 개발자 모드에서만 |
| **모드 설치 개선** ✅ | 도구 → 모드 설치에서 zip 말고 **폴더 선택**과 **7z**도(LZMA SDK). rar는 "압축을 풀어 폴더로 골라 주세요" 안내 |
| **숫자 설정 직접 입력** ✅ | 제보: 런처에서 너비·높이가 안 바뀜(←/→로만 80씩 바뀌고 클릭은 반응 없음). 숫자 줄을 클릭하면 숫자 전용 입력 창(키보드 숫자키·키패드, Num Lock 꺼져도). 런처에서 키보드 입력이 아예 안 들어가던 것도 고침 |
| **화면비 고르기** ✅ | F1 → 화면의 화면비가 1.78처럼 숫자로만 나와 알아보기 어려움 → **자동 / 16:9 / 16:10 / 21:9 / 32:9 / 4:3 / 사용자 지정**(가로÷세로 숫자 입력)에서 고름 |
| **게임이 꺼지지 않고 남음** 🔧 | 게임을 꺼도 가끔 작업 관리자에 남아 있던 것(그래픽 드라이버 정리 단계에서 멈춤). 이제 정리가 5초 안에 안 끝나면 프로세스를 바로 끝냄. 재시작도 이걸 기다리느라 늦던 것 같이 해결 |
| **21:9 길드 카드** ✅ | HUD 위치 "양 끝"에서 카드 오른쪽 테두리가 떨어져 화면 끝으로 가고, 페이지 숫자의 바탕판이 검은 상자로 남던 것. 무기 사용 횟수 페이지의 그래프 아이콘·숫자가 카드 밖으로 나가고 탭이 고를 때마다 움직이던 것. 테두리는 카드와 함께, 바탕판은 페이지 숫자와 함께, 창 안에 그려지는 것은 그 창과 함께 |
| **런처가 꺼지지 않고 남음 / 가끔 안 켜짐** ✅ | 런처 창을 닫아도 가끔 작업 관리자에 남아 있던 것: 끝나지 않은 확인 작업(업데이트 확인, 그래픽카드 Vulkan 검사 등)을 기다리느라. 이제 창은 바로 사라지고, 백업 같은 작업은 끝까지 마친 뒤 프로세스가 반드시 끝남(최대 10초). 더블클릭해도 가끔 안 켜지던 것: Vulkan 검사를 창이 뜬 뒤로 미룸(창 만들기와 동시에 하면 드라이버·오버레이가 멈출 수 있음). 런처의 시작·종료 단계를 `launcher.log`에 남김(문제 보고에 포함) |
| **21:9 아이템 박스 창 밀림** ✅ | 제보: 16:9보다 넓은 화면(HUD 위치 "양 끝")에서 아이템 박스 창이 왔다 갔다 함. 아이템 설명 창과 박스가 좌우 대칭으로 놓여 있어 "가운데 대화창 하나"로 잘못 판단 → 설명이 보일 땐 가운데, 빈칸·아이템 옮길 땐 오른쪽 끝. 이제 둘을 따로 놓아 설명은 왼쪽, 박스는 늘 오른쪽. (제보 사진이 잘려 보인 건 메신저 미리보기가 양옆을 자른 것) |
| **텍스처 뽑기 속도** ✅ | 고해상도 텍스처 만들기의 첫 단계(뽑기, 30분 이상)를 최대 8개 코어로 나눠 하고 PNG 압축을 가볍게. 결과는 전과 똑같음 |

# MHXX Recomp 0.10.10

## 새 기능

- **영문판 플러그인 2개가 더 동작합니다**
  - **Key Quest Markers** (PurplefinNeptuna님): 퀘스트 목록에서 키 퀘스트·긴급 퀘스트에 배지를 붙여 줍니다 (진행에 필요한 키 퀘스트 초록, 긴급 빨강, 깬 것 회색).
  - **World(like) Sharpness Gauge** (PurplefinNeptuna님): 날 게이지를 월드처럼 바꿉니다. 런처 → 모드에서 **`00_KatLib`보다 위로** 올려 주세요.
  - 받는 곳과 설치법: [영문판 플러그인 호환 목록](../gu-plugins.md)

## 고친 점

- **플러그인을 여러 개 쓸 때 게임이 갑자기 튕길 수 있던 문제를 고쳤습니다.** 영문판 플러그인용으로 포트가 마련한 메모리 영역이 게임 메모리와 겹쳐 있었습니다.
- 스킬 시뮬레이터: + 메뉴에서 커서를 올리면 설명 문구가 나옵니다.

## 알아 두기

- 멀티는 같이 하는 사람 모두 **0.10.10**이어야 합니다.
- 인터넷 통신(허브 서버)을 쓰면 서버 관리자에게 접속 IP와 닉네임이 보입니다. 트롤·신고 처리(밴)에만 쓰고, 접속 기록은 3일 뒤 자동으로 지워집니다. 원하지 않으면 허브 서버를 끄고 로컬 통신이나 라드민으로 하시면 됩니다.

## 테스트 환경

Windows 11, AMD 라이젠 7 5700X3D, RTX 3070 Ti (8GB), 메모리 32GB

# MHXX Recomp 0.10.3

> 멀티플레이는 같이 하는 사람 모두 **0.10.3**으로 업데이트해 주세요. 0.10.2 이하와는 같이 플레이할 수 없습니다. 런처를 켜면 업데이트 안내가 뜹니다.

다운로드(DL) 이벤트 퀘스트가 한글로 나오고, 3DS판 세이브를 가져올 수 있습니다.

## 새 기능

- **DL(이벤트·챌린지) 퀘스트 한글**
  - 스위치에서 받은 DL 퀘스트가 일본어로 나오거나 글자가 깨지던 것을 고쳤습니다. 퀘스트 목록, 상세 설명이 한글패치의 번역으로 나옵니다.
  - 원인: 스위치판은 DL 퀘스트를 받을 때 퀘스트를 세이브 안에 복사해 둡니다. 한글패치 없이 받은 세이브에는 일본어 사본이 들어 있어서, PC에서 한글패치를 넣어도 일본어가 나왔습니다.
  - 이제 게임이 세이브를 읽을 때 세이브에 있는 DL 퀘스트를 한글패치의 같은 퀘스트로 바꿔서 보여 줍니다. 한글패치를 넣었을 때만 동작합니다.
  - 세이브에 이미 있는 퀘스트만 바뀌고, 없는 퀘스트가 새로 생기지는 않습니다. 세이브 파일은 게임에서 저장할 때 한글 사본으로 저장됩니다.
  - 세이브를 올려 주신 분 덕분에 고칠 수 있었습니다. 감사합니다.

- **3DS / 스위치 세이브 가져오기**
  - 런처 → 도구 → 세이브 백업 → **3DS / 스위치 세이브 가져오기**에서 세이브의 `system` 파일을 고르면 이 포팅의 세이브로 넣습니다.
  - 3DS판 덥크 세이브는 스위치 형식으로 바꿔서 넣습니다. 고른 원본 파일은 바뀌지 않습니다.
  - 넣기 전에 지금 세이브를 "세이브 가져오기 전" 백업으로 남깁니다. 잘못 넣었으면 그 백업을 복원하세요.
  - 3DS 세이브는 게임 옵션의 밝기 설정이 그대로 넘어와서 화면이 어둡게 보일 수 있습니다. 게임 안 옵션에서 밝기를 올려 주세요.
  - 3DS판의 DL 퀘스트는 세이브가 아니라 따로 저장되어 있어서 같이 옮겨지지 않습니다.

## 바뀐 점

- **버그 제보는 깃허브 이슈로**: 이슈 탭을 열고 한국어 양식을 만들었습니다. "버그 제보"와 "DL(이벤트) 퀘스트 한글 깨짐" 양식이 있고, 스크린샷과 런처 → 도구 → 문제 보고 파일을 바로 올릴 수 있습니다.
  - https://github.com/SDK1175/MHXXRecomp/issues
  - 올린 사진과 파일은 누구나 볼 수 있으니 헌터 이름은 가려 주세요.
- 설명서에 3DS 세이브 가져오기를 추가했습니다.
- 게임 파일 설치에서 키 파일(prod.keys)을 다른 프로그램 폴더에서 자동으로 찾지 않습니다. **찾아보기**로 직접 골라 주세요.

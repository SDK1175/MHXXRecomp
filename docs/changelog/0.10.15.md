# MHXX Recomp 0.10.15

허브 서버 운영(신고 처리)을 위한 업데이트입니다. 게임 플레이에서 바뀌는 점은 없습니다.

## 고친 점

- **허브 서버에 전달되는 이름:** 지금까지는 포팅 설정의 닉네임(대부분 "Hunter")이 서버에 전달되어, 신고가 들어와도 방에 누가 있는지 알아보기 어려웠습니다. 이제 **게임 속 헌터 이름**이 전달됩니다. 한글 이름도 그대로 보입니다.
  - 세이브를 불러오기 전에는 예전처럼 닉네임이 전달됩니다.

## 알아 두기

- 멀티는 같이 하는 사람 모두 **0.10.15**여야 합니다.
- 인터넷 통신(허브 서버)을 쓰면 서버 관리자에게 접속 IP와 **헌터 이름**이 보입니다. 이 정보는 트롤·신고 처리(밴)에만 쓰고, 접속 기록은 3일 뒤 자동으로 지워집니다. 원하지 않으면 허브 서버를 끄고 로컬 통신이나 라드민으로 하시면 됩니다.

## 테스트 환경

Windows 11, AMD 라이젠 7 5700X3D, RTX 3070 Ti (8GB), 메모리 32GB

# MHXX Recomp 0.10.1

> 멀티플레이는 같이 하는 사람 모두 **0.10.1**로 업데이트해 주세요. 0.10.0과는 같이 플레이할 수 없습니다. 0.10.0을 받으신 분은 런처를 켜면 업데이트 안내가 뜹니다.

0.10.0을 쓰면서 나온 불편한 점을 고친 작은 업데이트입니다.

## 바뀐 점

- **백그라운드 FPS**
  - 게임을 켜 둔 채로 Alt+Tab 등으로 다른 창(브라우저, 메신저 등)을 보고 있으면, 그동안 게임이 30fps로 내려갑니다.
  - 지금까지는 게임이 뒤에서도 설정한 FPS(최대 240)로 그래픽카드를 꽉 채워 써서, 다른 프로그램이 버벅일 수 있었습니다.
  - 게임 창을 다시 누르면 원래 FPS로 바로 돌아옵니다.
  - F1 → 성능 → **백그라운드 FPS**에서 바꿀 수 있습니다. 0으로 하면 이 기능이 꺼집니다.
  - 모니터를 두 개 쓰면서 다른 모니터를 보는 동안에도 게임 화면이 부드러워야 한다면 0이나 60으로 바꿔 주세요.

- **게임 중 업데이트 알림**
  - 플레이하는 동안 깃허브에 새 버전이 올라오면 화면 왼쪽 아래에 작은 알림이 잠깐 뜹니다. 혼자 할 때도, 멀티 중에도 똑같습니다.
  - 게임을 켜고 1분 뒤, 그 뒤로 30분마다 확인합니다. 같은 버전은 한 번만 알려 줍니다.
  - 알림만 띄우고 다운로드나 설치는 하지 않으니 플레이가 끊기지 않습니다. 업데이트는 게임을 끈 뒤 런처에서 하면 됩니다.
  - 런처의 업데이트 확인과 같은 깃허브 주소만 확인합니다.
  - F1 → 응용 프로그램 → **게임 중 업데이트 알림**에서 끌 수 있습니다.

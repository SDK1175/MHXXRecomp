# MHXX Recomp 0.10.1

> **멀티플레이를 하시는 분은 같이 하는 사람 모두 0.10.1로 업데이트해 주세요.** 0.10.0과는 같이 플레이할 수 없습니다. 런처를 켜면 업데이트 안내가 뜹니다.

0.10.0을 쓰면서 불편했던 점을 고친 업데이트입니다.

## 바뀐 점

- **백그라운드 FPS**: Alt+Tab 등으로 다른 창을 보고 있을 때는 30fps로 낮춥니다. 게임을 켜 둔 채로 브라우저나 다른 프로그램을 써도 컴퓨터가 버벅이지 않습니다. 게임 창으로 돌아오면 원래 FPS로 올라갑니다. F1 → 성능 → 백그라운드 FPS에서 바꿀 수 있습니다(0: 끄기). 모니터를 두 개 쓰면서 다른 모니터를 보는 동안에도 게임이 부드러워야 한다면 0이나 60으로 바꿔 주세요.
- **게임 중 업데이트 알림**: 플레이하는 동안 깃허브에 새 버전이 올라오면 왼쪽 아래에 작게 알려 줍니다(혼자 할 때도, 멀티 중에도). 받기와 설치는 하지 않으니 게임을 끈 뒤 런처에서 업데이트하면 됩니다. F1 → 응용 프로그램 → 게임 중 업데이트 알림에서 끌 수 있습니다.

# 영문판(MHGU) Forge 플러그인 호환 목록

영문판 MHGU 1.4.0용 Forge 플러그인(`.nro`)을 이 포팅(덥크 일어판 1.5.1)에서 쓴 결과입니다. 플러그인 파일은 고치지 않고
그대로 `mods\모드이름\romfs\nativeNX\plugins\`에 넣습니다. 포팅이 영문판 주소를 덥크 주소로 바꿔 보여 줍니다.

- 이 목록의 모드는 각 제작자의 것입니다. 이 포팅은 어떤 모드도 배포하지 않습니다. 받는 곳은 [MHGURecomp-mods](https://github.com/Oddity-git/MHGURecomp-mods) 목록을 참고하세요.
- 영문판과 덥크의 게임 내부가 다른 부분을 쓰는 기능은 동작하지 않을 수 있습니다. 안 되는 기능은 플러그인이 스스로 끄거나, 로그(`log.txt`)에 이유가 남습니다.
- 세이브 데이터를 건드리는 플러그인은 **세이브를 백업한 뒤** 써 주세요.
- 써 보신 결과(되는 것 / 안 되는 것)는 깃허브 이슈나 구글 폼으로 알려 주세요. 문제 보고 zip에 로그가 들어갑니다.

## 데이터 모드 (텍스처)

> **데이터 모드는 더 이상 따로 맞추지 않습니다.** 앞으로의 호환 작업은 **Forge 플러그인(.nro)** 위주로 합니다. 아래의 텍스처 옮기기와 지금 동작하는 모드(IAI SLASH HELM BREAKER 등)는 그대로 유지되지만, 새 데이터 모드(모션·무기 동작·수치 데이터 등)는 동작한다는 보장이 없고 요청을 받아도 작업하지 않을 수 있습니다.

영문판용 데이터 모드(예: Xbox Controller Layout, Monster Weakness Icons)도 그대로 `mods\모드이름\romfs\`에 넣으면 됩니다.
영문판은 파일 위치가 덥크와 달라서(`nativeNX/eng/...`, `nativeNX/loc/...`), 포팅이 게임을 켤 때 덥크 위치로 옮겨 넣습니다.

- **텍스처만** 옮깁니다. 메뉴 배치(.gui)·글씨(.gmd) 같은 데이터는 덥크와 달라 넣으면 화면이 깨지거나 영어로 바뀌므로 옮기지 않습니다(로그에 개수가 남습니다).
- 모드가 **실제로 바꾼 그림만** 옮깁니다. 영문판 모드에 같이 들어 있는 영문판 원본 그림은 덥크 것을 덮지 않습니다.
- 메뉴 그림은 아이콘과 글씨가 한 장에 같이 있어서, 모드가 그린 **부분(16×16 칸)만** 덥크 그림 위에 얹습니다. 그래서 버튼 아이콘 모드를 넣어도 같은 그림의 한글(한글 패치)은 그대로 남습니다.
- 처음 켤 때 한 번 만들어 `cache\gumods`에 두고, 다음부터는 바로 씁니다.
- 텍스처 팩에 같은 그림이 있으면 텍스처 팩 쪽이 먼저입니다.
- 모드가 그림 속 **영어 문구 자체를 고친** 경우, 그 부분은 모드의 영어 그대로 들어옵니다. 한글로 바꾼 그림을 텍스처 팩으로 넣으면 그쪽이 쓰입니다.
